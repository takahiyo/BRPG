# 灰灯の迷宮 / ASHEN ATLAS (BRPG)

依存ライブラリなしのブラウザRPG試作 v3 と、今後の拡張に向けた創作データ・システム設計辞典（全1,765項目＋各種ルール・検証スクリプト）を統合したリポジトリ。

---

## 1. ブラウザゲーム試作 v3（現行プレイアブル版）

Obsidian原案をもとに、6人パーティー・ランダム遭遇・コマンド戦闘・素材加工・段階的な自動化を実装。

### 起動

`index.html` をブラウザで開くか、PowerShellで次を実行する。

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

[プレイ画面](http://127.0.0.1:8765/)。既に起動している場合、サーバーの再起動は不要。ブラウザの再読み込みで変更を反映する。

### 基本操作

- 街の「地図」「依頼」で既知の地域から目的地を選択。常設納品を繰り返し、時折届く好条件・緊急依頼にも挑戦。最初はLv1の林縁。
- 矢印/WASDまたは地図の矢印で歩行。ランダムで遭遇し、地図横で仲間・行動・対象を選んで指示を確定し、「全員の行動を実行」。名前を押すと詳細ステータス。
- 自動操作は「歩行＋戦闘」「歩行のみ」「戦闘のみ」を選択。「歩行＋戦闘」は勝利後3秒待って再開し、停止・手動操作で中止できます。初期の探索者が同行している間は右手法・通常攻撃のみ利用可能。同行しない場合は行動書が必要。階段、封印、詳細画面、全滅などでは停止。
- 宿屋・商店・神殿は独立施設。宿は生存者を回復、神殿は蘇生・解毒・覚醒。入口以外の帰還は帰還符、または探索者のSP3即時帰還。LIFE/MANA/SPの残量を見て引き返す。
- 酒場で仲間を募集・転職。一人一職、最大6人参加・16人登録。36戦闘職と発見した職能証の職業。仲間詳細で装備変更、成長ポイントの仮配分・確定・取消、人物切替。編成セットは3枠。
- 隊列は前衛・後衛各3枠。近距離は前衛から敵前衛へ、槍・鞭は味方後衛からも敵前衛へ、弓・杖・攻撃魔法は敵後衛も狙えます。前衛が倒れると後衛へ接敵。編成セットには参加メンバーと全員の隊列を保存します。
- 新規開始時の後衛（僧侶・軍師）は木製の杖を持ち、後衛から攻撃できます。旧セーブの装備はそのまま保持します。自動入力は最後のMANAと設定済みの温存を守り、届く行動がなければ防御します。
- 採集と戦利品は別。素材64種、付呪18種。工房で加工・品質を選び、仲間の持ち物画面で装備します。高品質ほど費用と必要素材品質が上がる。
- 「手帳」で素材・魔物・職業・加工法を切り替えて閲覧。売却は商店。敵の現在LIFE・Lvの観測には適した職業が必要。アドレスからLv80〜300の街と探索地を発見し、高級工房や拠点購入を目指せる。

個人の持ち物には装備中の品も含みます。職業系統ごとの容量は8〜20枠、装飾品は1〜2枠。武器・盾・頭・身体・腕・脚・装飾品を装着でき、両手武器と盾は併用できません。職業適性外では基礎性能50%、特殊効果無効。能力条件は別途必要です。あふれた入手品は街の倉庫へ保管し、転職で容量を超えた既存品は保持します。全滅時は参加者の持ち物も回収対象になります。

部位を押すと所持品・倉庫の候補を表示します。お任せ装備は候補の出所を選択でき、未装備の所持品は倉庫へ一括移動できます。魔法職は金属装備・盾を装備できず、旧保存に残る禁止装備も性能無効です。酒場では転職の能力・所持枠・装備適性を比較、工房では識別済み素材の完成性能を予測できます。商店は購入/売却と購入品の部位分類、ギルドは依頼種別と即納・報告可能の表示で選べます。

### 保存と検証（v3エンジン）

画面下の「保存先・Google連携」でローカル保存とGoogleアカウントによるクラウド保存を選択できる。既定はローカル保存。クラウド接続時に読み込み／現在の冒険の送信を確認し、別端末との更新競合は自動上書きしない。再読み込み後は端末の控えから再開し、クラウド利用時は再ログインして接続する。クラウドの利用にはGoogle OAuth設定とCloudflare Worker/D1が必要。構成・設定・未確認事項は [CLOUD_SAVE.md](CLOUD_SAVE.md)。

`ashen-atlas-v3` に自動保存。`ashen-atlas-v2` がある場合は初回に変換し、元キーは残す。v1も上書きしないが、v1からの直接変換は行わない。破損した保存は別キーへ退避し新規開始。再読み込み時に自動探索は停止状態になる。保存はブラウザ・オリジンごとに別で、localhostと127.0.0.1は異なる。

```powershell
node test.cjs
node test-regression.cjs
node test-overhaul.cjs
node test-equipment.cjs
node test-exploration.cjs
node test-save-manager.cjs
node test-quest-travel.cjs
node test-build-pages.cjs
node test-formation.cjs
node test-combat-balance.cjs
```

距離戦闘の計測は5編成・3地域・30固定シードを2回実行し、再現性と自動行動の安全性を検証します。条件・実測値・未検証範囲は [距離戦闘の固定シード計測](docs/COMBAT_BALANCE.md) を参照してください。

実ブラウザの回帰テストはNode.js 22以降とインストール済みChrome/Edgeを使用します（追加パッケージ不要）。Windowsの標準インストール先は自動検出し、それ以外は `BRPG_BROWSER` にChromium実行ファイルを指定します。専用の一時プロファイルを使い、普段の保存データには触れません。

```powershell
node test-browser.cjs
node scripts/build-pages.cjs
node test-browser.cjs --dist
```

1280/390/320pxで主要画面・長い名前の折返し・装備変更・編成保存/呼出し・転職・購入・工房製作・保存画面・戦闘対象選択とターン実行を確認します。`--screenshots` を付けると一時ディレクトリへ画面PNGを出力します。headless Chromiumの検証であり、実機タッチ・Google実認証・外部保存APIの確認は含みません。

自動検証の保証範囲と残課題・今後の統合計画は [DEVELOPMENT.md](DEVELOPMENT.md)。引き継ぎは [AGENTS.md](AGENTS.md) と [HANDOFF.md](HANDOFF.md) から開始。原案整理は [WORLD_AND_DESIGN.md](WORLD_AND_DESIGN.md)、追加職業・ステータス案は [CHARACTER_SYSTEM.md](CHARACTER_SYSTEM.md)、v3データ一覧は [CONTENT_CATALOG.md](CONTENT_CATALOG.md)。
