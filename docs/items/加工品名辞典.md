# 加工品名辞典（試案）

関連：[[アイテム命名ルール]]・[[称号辞典]]・[[アイテム名の組合せ例]]・[[素材：鉱石など]]

「称号＋素材＋加工品名」で道具名を組み立てるための、加工品側の基本名辞典です。適正LV下限・上限は出現帯の仮案として1〜300で持ち、数値性能・価格・希少度は扱いません。全540件のうち武器180件、防具150件、その他210件です。名称と分類はゲーム用の試案で、歴史的な分類の厳密な統一を目的としません。

## 組み立て方と素材の範囲

- 接続は「称号＋素材＋の＋加工品名」です。例：`木の槍`、`金属のランタン`。称号には連体形まで含めます。詳細は[[アイテム命名ルール]]を参照してください。
- 素材は完成品全体の単一素材を意味せず、各行の「素材を掛ける部位」を指します。穂先指定の槍に素材を付ける場合は穂先を、柄指定の手槍では柄を想定します。一般名の「槍」は穂先と柄を選択でき、「木の槍」では柄、「金属の槍」では穂先を既定として扱えます。
- `金属のランタン`の金属は枠、`木の盾`の木は盾面、`布の天幕`の布は幕地を指します。留め具・柄・芯・刃・覆いなど、ほかの部品には別素材を使えます。
- 素材タグ候補は生成時に許可する主部材カテゴリです。加工品カテゴリと特徴も機械判定に使います。詳細は[[アイテムカテゴリ規則]]を参照してください。弓弦、灯芯、容器の内張りなどは必要なら別の部品属性を持たせます。
- 「骨角」は骨・角・牙の系統、「糸」は繊維を撚ったもの、「草」は葦・蔓などの編み材も含む便宜的なタグです。金属・木・石などの上位タグを、別の素材辞典の固有素材名へ置き換えて使えます。

## 同義語と試案名の扱い

- 品名は表記の異なる同義語を際限なく追加せず、基本形を一つ選びます。「たいまつ／松明」などの検索用別名は別の別名表で扱い、この辞典の別IDにはしません。
- 似た品名でも、形状・携行方法・構造・使用部位が異なるものは独立候補です。例えば「丸盾／拳盾」は形状と使用法という異なる軸から名付けた候補なので、設定上は同じ物に両方が当てはまる場合もあります。採用時に同義と決めた候補は別名として統合してください。
- 一般カテゴリと具体形の両方を収録しています。例えば「盾」は分類未定時の基本名、「凧盾」は形を指定する基本名です。階層関係は同じ物の二重所持を意味しません。
- 固有作品の名物武器、既存キャラクター名、品質・状態・職人を表す接頭辞は入れていません。一部の説明的な複合名も正式な史料用語と断定せず、採否を調整する試案として扱います。
- IDは全節を通じて一意です。採用後は既存IDを再利用せず、追加は末尾の次番号にしてください。
