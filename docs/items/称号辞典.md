# 称号辞典

関連：[[アイテム命名ルール]]・[[加工品名辞典]]・[[アイテム名の組合せ例]]・[[素材：鉱石など]]

「称号＋素材＋の＋加工品名」で組み立てるための名称候補。例：**ボロボロの鉄の剣**、**上質な樫の椅子**。全400語。適正LV下限・上限は出現帯を絞るための1〜300の仮案で、数値性能・価格・能力付与は定義しない。

機械判定は各行の「素材カテゴリ条件」「加工品カテゴリ条件」「必須特徴」を使う。条件列内のカンマはOR、列間はAND、`*` はその条件を限定しない。必須特徴の `-` は追加条件なし。旧「適用タグ」は発想用の参考として残すが、判定には使わない。意味欄は外見や来歴から読み取れる価値の手がかり。詳細は[[アイテムカテゴリ規則]]を参照する。

人物・工房・組合・地名はすべて、この辞典のための**未採用の設定案**。既存の世界設定を確定しない。神秘的な称号も伝承・意匠・評判を表し、実際の魔法効果や加護を保証しない。
