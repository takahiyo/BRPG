# アイテムカテゴリ規則

[[称号辞典]]400件、[[加工品名辞典]]540件、[[素材LV辞典]]のカテゴリと適正LVを使い、組合せ可能な名前だけを抽選するための仮案。名前やIDは維持し、辞典の条件列を判定の根拠にする。攻撃力・価格・魔法効果を決める規則ではない。

## 判定する条件

次の条件を**すべて満たす**組合せを許可する。

1. 素材のカテゴリと、加工品の「素材タグ候補」が1つ以上一致する。
2. 素材のカテゴリと、称号の「素材カテゴリ条件」が1つ以上一致する。
3. 加工品のカテゴリと、称号の「加工品カテゴリ条件」が一致する。
4. 称号の「必須特徴」が、加工品の「特徴」にすべて含まれる。
5. 称号・素材・加工品の適正LV範囲に共通部分がある。`--level` 指定時は、そのLVも共通部分に含まれる。

素材条件と加工品条件は**AND**。各条件列内のカンマは**OR**。`*` はその条件を限定しない。特徴列の `-` は特徴指定なし。必須特徴を複数にする場合は全特徴が必要で、ORにはしない。旧「適用タグ（参考）」は発想のヒントとして残し、機械判定には使用しない。

例えば「鍛冶師ベルカドの」は素材が金属、加工品が武器・防具・工具のいずれかである必要がある。金属に合うだけの杯や、武器に合うだけの木の棍棒は通らない。「織り手セリオナの」は布、「三枝木工房の」は木、「灯具師エルセクの」は照明を要求する。

「錆に覆われた」「防錆油の香る」は鉄系を要求する。金属一般ではないので、木の盾、布の鎧、銅のランタンには付かない。「刃こぼれした」「研ぎ直された」「研ぎ師オルダクの」「西門刃工連盟の」は金属・石・骨角のいずれかに加えて `刃物` を要求する。武器カテゴリの棍棒や、金属のランタンは刃物扱いしない。

## 共通カテゴリ

| 対象 | 正式なカテゴリ値 | 意味 |
| --- | --- | --- |
| 素材 | 金属,鉄系,木,石,骨角,布,革,糸,草,ガラス,陶磁,蝋,紙,液体,魔力 | 素材辞典に明記した主材の系統。鉄系だけは金属も持つ |
| 加工品 | 武器,防具,照明,野営,容器,工具,生活,商具,装身具 | 各加工品に1つ付ける。元の18章は細分類・検索用として残す |
| 特徴 | 刃物,接合,柄,錠,連環,折畳,金具 | 加工品の採用案に実在する構造。名前から実行時に推測しない |

照明は灯具、野営は探索・移動・野営道具、生活は調理・食事・生活用品、商具は商い・記録・計量道具を含む。装身具は祭具・小物も含む。杯・皿は生活、祭杯は装身具だが、容器職人や食卓の称号は必要に応じて両カテゴリを許可してある。

`接合` は部材の接ぎ合わせ、`柄` は差し替え可能な持ち手、`錠` は箱類に備えた錠、`連環` は輪・鎖の構造、`折畳` は畳める機構、`金具` は締め直せる金具を採用する案。この特徴がない一般形に称号を付けたい場合は、対象行の構造案を確認して特徴を明示追加する。別部品の材質を細かく生成するものではない。

加工品の素材は「素材を掛ける部位」の主部材を表す。たとえば木の槍の木は柄、金属の槍の金属は穂先。「刃こぼれした」のように主材にも制約を置いた称号では、木の槍は通さず、刃の素材を表示した候補を選ぶ。木の櫛という既存例に合わせ、櫛 P0526 は木も許可する。

## 素材の名前・別名

カテゴリとLVの正本は[[素材LV辞典]]。既存の[[素材：鉱石など]]にある原文名を残し、表示名を別列に持つ。生成器は**原文名と明示された表示名**を同じ素材として受け付ける。原文名の括弧を除いた名前も、曖昧でなく、別の明示表示名と衝突しない場合だけ受け付ける。同名の作品別素材は正本の区別された表示名で指定する。表示する完成名には入力名をそのまま使う。

| 原文名の例 | 表示名の例 | 系統の例 |
| --- | --- | --- |
| 木材 | 木 | 木 |
| 鉄（アイアン） | 鉄 | 金属,鉄系 |
| 鋼（スチール） | 鋼 | 金属,鉄系 |
| 銅（カッパー） | 銅 | 金属 |
| 青銅（ブロンズ） | 青銅 | 金属 |
| 黄銅（真鍮） | 真鍮 | 金属 |
| 銀（シルバー） | 銀 | 金属 |
| 金（ゴールド） | 金 | 金属 |
| 水晶・翡翠などの鉱物 | 素材辞典の表示名 | 石 |

この表は読み方の例であり、二重の分類表ではない。布・革・糸・草・ガラス・陶磁・蝋・紙など、既存素材メモにない主材は素材LV辞典側で「補完案」として区別する。原料鉱石を完成金属に自動変換しない。架空素材の字面から「金属らしい」「木らしい」と推測しない。

未登録素材は、コマンドでカテゴリとLV範囲の両方を明示した場合だけ使える。

```powershell
python scripts/generate_item_names.py --material 星樫 --material-tag 星樫=木 --material-level 星樫=40:120 --title 上質な --product 盾 --level 50 --count 1
```

既知素材の分類・LVをコマンドで上書きすることはできない。採用案を変える場合は正本を修正する。`--dictionary-dir` で別の称号・加工品辞典を指定する場合、既定の素材辞典はその隣の `materials/素材LV辞典.md`。別配置なら `--material-dictionary` で明示する。

## 適正LV

適正LVは1〜300の整数範囲で、対象レベルの敵から拾える候補を絞るための仮案。一般的な型・たいまつなどの日用品は広い範囲で残し、上質・名工・精緻な工芸や複雑な加工品には下限を付ける。タイトルの「伝承」が実在の魔力を保証することはない。

完成品の範囲は `下限=max(称号下限, 素材下限, 加工品下限)`、`上限=min(称号上限, 素材上限, 加工品上限)`。下限が上限を超える候補は、LVを指定しなくても除外する。`--level 30` なら3者すべてがLV30を含む候補から抽選する。出力にはこの完成品範囲を表示する。

適正LVを戦闘力・売価・希少度へ変換する式は未定義。高LVだから日用品が消える設計にはせず、素材や称号で出現帯を調整できる。

## 検証

`python -m unittest discover -s scripts -p "item_test_*.py" -v` で、辞典件数・連続ID・条件語彙、既存の組合せ例、適合・不適合、LV境界、重複排除、seed再現を確認する。辞典を変更したら再実行する。カテゴリ適合後も、日本語の語感、世界観、細部の製法は採用時に確認する。

2026-10-19作成時は18テストが成功。称号400件・加工品540件の連続IDと一意な名称、全行の範囲が1〜300に収まること、全40例の適合、全称号・全加工品に少なくとも1つ適合候補があることを確認した。木・布・銅の錆、ランタン・棍棒の刃こぼれ、素材条件だけ／加工品条件だけの一致、LV範囲外・範囲不交差は拒否し、seed固定の100件は重複なく再現した。

独立検証を受け、鎖帷子・鎖胴着・鎖シャツ・環鎧の素材対象を鎖／環に明示し、金属に限定した。布や革の鎖鎧を排除する確認も追加した。
