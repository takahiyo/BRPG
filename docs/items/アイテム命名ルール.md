# アイテム命名ルール

冒険で拾う装備と行商で売買する商品を、**称号＋素材＋の＋加工品名**で表す。今回は名前と分類だけを準備する。攻撃力、防御力、耐久値、重量、価格、希少度、抽選確率は未設定。

## 辞典と既存ノート

- [[称号辞典]]：20分類・400件。状態、品質、製作者、工房、産地、来歴、意匠、商慣習、神秘的な呼び名。
- [[加工品名辞典]]：18分類・540件。武器180件、防具150件、照明・野営用品・道具・容器・装身具など210件。
- [[素材：鉱石など]]：既存の素材メモ。素材の候補・特徴・作品例はこちらを参照する。
- [[素材LV辞典]]：素材名・表示名・素材カテゴリ・適正LVの機械判定用正本。
- [[アイテムカテゴリ規則]]：称号・素材・加工品の条件とLV範囲を照合する共通規則。
- [[アイテム名の組合せ例]]：組合せの見え方と、価値の差を考える例。

Obsidianでは各ノートのプロパティ `タグ` に `創作` を付け、既存の「創作.base」の `タグ.containsAny("創作")` に合わせる。本文は通常のMarkdownとして記録する。

## 接続ルール

```text
称号表示文字列 + 素材表示名 + "の" + 加工品名
ボロボロの     + 木         + の   + 盾
上質な         + 鋼         + の   + 槍
```

称号は接続語まで含める。「上質」にさらに「の」を足すといった自動補正はしない。素材は接続語を含めない。素材名自体に「の」がある「世界樹の木材」などもそのまま扱い、完成品では「世界樹の木材の杖」となる。長ければ素材の表示用別名を別途決める。

「木材→木」「鉄（アイアン）→鉄」「鋼（スチール）→鋼」「銅（カッパー）→銅」「黄銅（真鍮）→真鍮」のように、資料上の見出しと表示名を分けてよい。元の素材名と対応関係を残し、別名を別素材として重複登録しない。これらは表示案で、既存メモを書き換えるものではない。

黄鉄鉱や赤鉄鉱などの原料を、そのまま完成品の金属として抽選しない。鉄鉱石を精錬した完成品なら「鉄の剣」、鉱物そのものを装飾に使った商品なら「黄鉄鉱の護符」とする。宝石は装身具の飾り、金属は刃・頭部・枠、木は柄・胴など、加工品辞典の「素材を掛ける部位」を手がかりにする。

## 抽選の手順

1. 武器、防具、照明、容器など、欲しい加工品の分類を決める。
2. 加工品名と、素材を掛ける部位を選ぶ。
3. 既存素材メモから、その部位に使う素材を選ぶ。
4. 称号の素材カテゴリ条件・加工品カテゴリ条件・必須特徴をすべて満たす称号を1つ選ぶ。
5. 称号・素材・加工品の適正LVに共通部分があることを確認する。指定LVがあれば3者すべてがそのLVを含む候補に絞る。
6. 接続して、語感・世界観・細部の製法を確認する。

初期は称号を1つにし、「ボロボロの上質な」のような相反する重ね掛けを避ける。将来複数に増やす場合は「来歴＋製作者＋品質」のように軸と語順を別設計にする。旧「適用タグ（参考）」はヒントとして残すが、機械判定は新しい条件列で行う。素材条件と加工品条件はAND、各条件列内の候補はOR。詳しくは[[アイテムカテゴリ規則]]を参照する。

「錆に覆われた」は鉄系だけ、「虫食いの」は木・布だけに付ける。「刃こぼれした」は刃物特徴を要求するため、武器でも棍棒には付かない。「銀の長剣」なども世界観によって実用品・儀礼品・銀張りで意味が変わるので、名称だけで製法を確定しない。全素材と全加工品の直積を、そのまま実在する商品一覧としない。

## 行商で価値を分ける観点

| 観点 | 価値の違いを付ける材料 | 名称から確定しないこと |
| --- | --- | --- |
| 製作者・工房 | 銘、評判、弟子作、注文品、工房の廃絶 | 名工の名があるだけで高性能とはしない |
| 産地・輸送 | 地方独自の意匠、都市での流行、産地の供給状況 | 産地だけで恒久的な値段を付けない |
| 来歴 | 旧王朝、巡礼、船旅、戦場、家宝 | 持ち主の伝説が事実とは限らない |
| 状態・修復 | 新品、使い込み、補修、磨き直し | 古いものが必ず安いとはしない |
| 意匠・収集 | 紋章、祭礼様式、廃版、揃い物の欠品 | 華美なものが必ず実用的とはしない |
| 証明・信用 | 刻印、保証、鑑定、由来を示す証文 | 名称と真贋を同一視しない |
| 買い手の需要 | 兵士、船乗り、貴族、寺院、収集家 | 需要の違いを戦闘力の差へ直結させない |

価格や倍率は後から決める。同じ基礎性能でも、工房や来歴を好む買い手に売る楽しさを作る。真贋や証明の状態は将来的に別データとして持てるが、今回は判定システムを設定しない。

神秘的な称号も呼び名・伝承の候補。「不滅」「祝福」「呪い」などの語だけで特殊能力を確定しない。辞典内の架空の人名・地名・工房名は設定のたたき台であり、既存世界への正式追加ではない。

## 名前候補を実際に抽選する

BRPGの `scripts/generate_item_names.py` は、称号・加工品・素材LVのMarkdown辞典を読み取るPython 3用の試作。追加ライブラリは不要。既存の素材メモを自動解釈せず、使いたい素材を指定する。カテゴリ条件と適正LVを満たす候補だけを、重複なしでMarkdown表へ出力する。語感や世界観は採用時に確認する。

BRPGフォルダで実行する例：

```powershell
python scripts/generate_item_names.py --material 木 --title ボロボロの --product 盾 --count 1
python scripts/generate_item_names.py --material 鋼 --title 上質な --product 槍 --count 1
python scripts/generate_item_names.py --material 鉄 --material 鋼 --product 短剣 --product 槍 --level 30 --count 30 --seed 19
python scripts/generate_item_names.py --material 木 --product-category 照明 --level 1 --count 5 --seed 19
```

`--title` と `--product` は完全一致で複数指定できる。`--title-category` は称号の章見出しの部分一致。`--product-category` は加工品カテゴリの完全一致、または元の章見出しの部分一致。`--seed` を固定すると、同じ辞典・同じ引数で結果を再現できる。辞典を並べ替えたり追記した場合は結果が変わりうる。

無指定の分類は全分類から抽選するが、素材と加工品、称号の素材条件と加工品条件、必須特徴、適正LVの共通部分をすべて確認してから抽選する。条件不一致の組合せを完全指定した場合は、候補なしのエラーになる。未知素材は名前から推測せず、`--material-tag 素材名=カテゴリ` と `--material-level 素材名=下限:上限` の両方が必要。`--dictionary-dir` と `--material-dictionary` で辞典の配置を変えられる。

`--level` は1〜300。未指定でも3者のLV範囲が重ならない候補は除外する。出力の「適正LV」は称号・素材・加工品の共通範囲。一般的な型やたいまつなどは高LVでも残るよう広い範囲にし、上質・名工・専門的な加工品には仮の下限を付けてある。LVは出現帯を絞るための値で、性能や価格ではない。

ゲーム本体への組込み、出現率調整、性能生成は今回の対象外。検証は `python -m unittest discover -s scripts -p "item_test_*.py" -v`。

## 参考にした資料と反映範囲

- [Blizzard：Diablo II / Magic Items](https://classic.battle.net/diablo2exp/items/magic.shtml)：接頭辞・接尾辞によるランダムな装備の多様化という発想を参考にした。本案では日本語の「称号＋素材＋加工品名」に置き換え、元の効果や数値体系は導入していない。
- [D&D Beyond：Basic Rules / Equipment](https://www.dndbeyond.com/sources/dnd/br-2024/equipment)：武器、防具、冒険用品へ分類を広げる際の参考。個別の説明文や性能表は転載していない。
- [Archives of Nethys：Pathfinder / Miscellaneous Equipment](https://www.aonprd.com/EquipmentMisc.aspx)：道具、衣類、動物装具、旅・商売向けの周辺用品という分類の幅を参考にした。

一般的な武具・道具の呼称と、それらを着想源にした独自の称号案を整理したもの。特定作品の全アイテム名を収集・再現した辞典ではない。既存素材メモの作品別出典はそのまま参照し、今回の新規称号の出典とは混同しない。
