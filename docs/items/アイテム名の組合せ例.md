## 同じ「鋼の短剣」を8つの名で見る

基礎性能が同じでも、状態・工房の評判・由来・買い手の好みを変えられる。下記の称号は価値づけの手がかりであり、自動的な値上がり・値下がりを意味しない。

| 完成名 | 称号ID | 商談の話題 |
| --- | --- | --- |
| ボロボロの鋼の短剣 | T0001 | 全体に著しい傷み |
| 新品同様の鋼の短剣 | T0021 | 使用痕がほぼ見えない |
| 粗製の鋼の短剣 | T0042 | 細部の処理が粗い |
| 上質な鋼の短剣 | T0041 | 材と仕上げが整う |
| 名工の鋼の短剣 | T0104 | 名の知られた職人の作 |
| 鍛冶師ベルカドの鋼の短剣 | T0121 | 寡黙な鍛冶師の銘 |
| 遺跡から掘り出された鋼の短剣 | T0201 | 発掘品という由来 |
| 一点限りの鋼の短剣 | T0227 | 同じ品の在庫がない |

例えば粗製品をまとめて買いたい護衛隊、工房銘を集める収集家、発掘品を探す好事家では、同じ鋼の短剣でも需要が変わる。売買価格や判定方法は後から設計する。
