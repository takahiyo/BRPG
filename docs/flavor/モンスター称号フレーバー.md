# モンスター称号フレーバー

関連：[[モンスター称号辞典]]・[[モンスター設計ルール]]・[[LV設計ルール]]・[[クラフトシステム設計]]

[[モンスター称号辞典]]の160件に対応する描写用の別表。ID・称号を照合キーとし、対象種族・必要特性・除外特性・LV補正・適正LVは元辞典だけを参照する。方向性と一文フレーバーは演出案であり、新しいカテゴリ、戦闘効果、数値保証を追加しない。実際の個体に存在する部位や習性に合わせて描写を採用する。

外見や行動の観察、所属や経験の記録、土地の評判、神話の伝聞を区別する。称号に含まれる千年・千戦・絶零・創世以前などの表現を、この表の一文だけで実測値や世界史の確定事項にしない。とくに災厄・神話の呼称は、語りの大きさと実際に確認された出来事を分けて扱う。

造物の機構・増設・量産という言葉だけでは製造年代や方式を確定しない。手仕事・鍛造・魔力成形・科学的な機械加工のうち実際に採用された工程を別途確認し、魔力成形の残留魔力がエンチャントを妨げることと、科学的な機械加工が低残留ゆえにより良いエンチャントの余地をつくることを混同しない。古代機構や伝統の道具すべてに産業科学を要求する設定にはしない。
