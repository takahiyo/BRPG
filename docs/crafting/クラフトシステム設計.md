# クラフトシステム設計

手工業と鍛冶が行き詰まる素材を魔法加工で先に実用化し、後から科学的な加工が追いつく。魔法加工は習得直後ほど魔力を浪費して大きな残留を生み、熟練すると改善する。最後に、精密な非魔法加工と高度なエンチャントの組合せが、最大の発展性を得る。

本書の数式・LV・魔力残留はBRPG用の暫定案。実在素材の加工をそのまま再現する工学シミュレーターではない。戦闘性能、価格、製作時間の実数は後で決める。今回作るのは、何を発見すれば何が作れるか、同じ品を作り直す理由が何かを確認できる土台である。

## 1. LVと解放条件を分ける

| 項目 | 範囲 | 役割 |
|---|---|---|
| キャラクターLV・ダンジョンLV・脅威度LV | 1〜300 | 冒険の難しさの共通目安 |
| 素材・加工品・称号の適正LV | 下限〜上限、各1〜300 | 出現・報酬候補の抽選。既存辞典を使用 |
| 加工LV | 1〜300 | 手工・鍛冶・機械・精密加工の技能 |
| 魔法加工LV | 1〜300 | 魔法成形の技能と魔力運用の効率 |
| エンチャントLV | 1〜300 | 付与できる術式の複雑さ |
| 発見済み技術・レシピ | IDの集合 | 知識の解放。技能だけでは代替できない |
| 設備 | 能力タグの集合 | 旋盤・焼結炉・測定器など。所持数値だけでは代替できない |

加工LV150の職人でも、旋盤と製法を知らなければ旋削品は作れない。冒険LV20でも交易で素材・技術・職人を集めれば高級品を扱える。冒険LVと技能LVを同一値に固定しない。松明など適正LV1〜300の道具は終盤にも残す。

出現候補は既存ルールどおり、称号・素材・加工品のLV区間の共通部分とカテゴリの適合で決める。加工難度は完成品の出現LVへ自動加算しない。高LVの敵が低LVの生活道具を持つことも許容し、報酬枠ごとの重みで主報酬だけを調整する。

## 2. 5つの加工経路

| 経路 | 位置付け | 長所 | ハードル |
|---|---|---|---|
| H：手工 | 切る・削る・編む・組む | 少ない設備で現地製作・修理 | 硬質材、大型精密品、複雑機構に限界 |
| F：炉・鍛冶 | 加熱・鋳造・鍛造・焼成 | 鉄鋼や量産部品を安定供給 | 温度、雰囲気、工具材質、内部組織を制御しきれない |
| M：魔法成形 | 魔力で素材へ直接干渉 | 工業技術の到来前に難加工材を成形 | 技能不足時の浪費、残留魔力、付与品質の上限 |
| I：機械工業 | 動力・切削・研削・焼結 | 非魔法加工で難素材と再現性を両立 | 専用設備、工具、冷却、計測の組合せ |
| X：精密科学 | 微細加工・精密測定・異相制御 | 高密度の術式を正確に収める | 最も重い研究・設備投資 |

この順序は社会の代表的な発展であり、全員に強制する一本道ではない。魔法から先に研究する都市、機械工業を輸入する商都、鍛冶を極める地方を併存させる。

魔力でモーターを回すだけで素材に直接魔法を掛けない機械はI/Xとしてよい。素材内部を魔法で軟化・変形させるなら、外見が機械でもMの履歴を残す。架空素材の異相切削工具は、刃先の物理的な共振を利用する設定とし、魔法で素材を変形させる代用品とは区別する。

## 3. 製作可否の共通判定

1. 素材カテゴリと加工品の許可カテゴリを照合する。
2. 素材と工程型の双方で選択経路が存在することを確認する。表の「-」はその経路では不可能。
3. 必要技能LV＝max（素材の経路LV、工程型の経路LV）＋加工品の形状加算LV。
4. 必要技能が300を超える組合せは現行設計では作れない。300へ丸めない。
5. 技術・加工品レシピ・設備をすべて確認する。複数設備はAND条件。
6. 対応する技能LVが必要値以上なら、主部材の製作を許可する。

技能不足を魔力の大量投入だけで踏み倒すことはできない。過渡期の浪費は「最低限の製作能力を得たが、まだ効率が悪い」段階に生じる。

表の素材は、特記がなければ成形に適した塊・板・棒・布などの加工用在庫を想定する。鉱石を買えば直ちに金属部品が作れるわけではない。採鉱→選鉱→製錬→合金化→素材在庫→部品→組立を区別し、鉱石から金属への変換には別レシピを設ける。

### 複合品の扱い

「鋼の槍」は鋼の穂先、木の柄、固定具から成る。命名素材は代表部位に掛かる。ランタンの金属枠を成形できても、ガラス・芯・燃料まで完成した扱いにはしない。今回の表と検証スクリプトは代表部位の可否を評価するもので、完成品の在庫消費や全BOMは未実装。

完全なレシピでは部品ごとに素材ID・数量・経路・必要技術・残留履歴を持ち、全必須部品と組立工程が揃って初めて完成する。形状加算を全部品に重複加算せず、各部品の難度と最終組立の難度を独立に定義する。

## 4. 魔法加工の過渡期と熟練

各素材の「魔法残留R0」は、最低技能で作る際の基準値（0〜100）である。必要技能をD、実際の魔法加工LVをMとする。

```text
技能余裕 s = M - D                          # 製作可能時だけ計算、s >= 0
過渡期係数 u = max(0, 1 - s / 60)
魔力消費倍率 C = 1 + 2u                    # 閾値直後3倍、余裕30で2倍、60以上で1倍
素材ごとの熟練下限 Rmin = ceil(R0 / 3)
今回の残留 Rnew = ceil(Rmin + (R0 - Rmin) * u)
```

基礎魔力コストは素材量・形状・工程時間ごとに将来設定し、その値にCを掛ける。CはキャラクターのMP総量を表す数値ではない。基礎MPを小さく見せるために分割加工しても、総加工量に掛かる費用は変えない。

必要魔法LV150・R0=66の仮想レシピなら、LV150で消費3倍／残留66、LV180で2倍／44、LV210で1倍／22。熟練魔法職人は大幅に改善できるが、直接魔法加工の残留をゼロにはできない。高難度レシピほど技能上限300までの余裕が少ないので、最難関素材には終盤でも強い過渡期が残る。

これにより、設備の乏しい時代には魔法加工装備が素材の選択肢で優位に立ち、付与が発展すると残留の少ない旧来素材の装備が逆転する場面が生まれる。機械加工が同じ難素材へ到達した時点で、素材と付与の両方を伸ばせる。

## 5. 残留は製作履歴として保存する

新しい非魔法加工はRnew=0。既存部材を再利用する場合、完成品の残留Rは「今回の残留と、付与対象構造を構成する部材の残留」の最大値を採用する。初期仕様では最大値方式とし、混合比による希釈を認めない。

- 魔法で成形した剣を機械で磨いても、内部の残留は消えない。
- 溶かし直し・合成・売買・改名・工房の変更でも履歴を継承する。
- 技能が上がっても、昔作った装備の残留は自動では下がらない。新しい未加工素材から作り直すと改善する。
- 自然由来の魔力親和性と、加工時に生じた乱れは別。魔石であるだけで残留を与えない。
- エンチャントそのものの正常な魔力は、加工残留として二重に数えない。
- 装飾宝石や着脱式の柄などを付与対象から分離できるかはレシピで明示する。プレイヤーが都合よく対象範囲を変えて残留を無視できないようにする。

浄化は初版では未解放とする。将来実装する場合も、製造時Rの保存、非ゼロの下限、再施術で下限が縮まらない規則を先に決める。今回は浄化を前提にバランスを取らない。

## 6. エンチャントの器となる加工品質

加工品質Q（0〜100）は、寸法・表面・組織の揃い方を表す仮指標。攻撃力や耐久力とは別である。

```text
Q = min(経路品質上限,
        経路品質基準 + floor((技能LV - 必要技能LV) / 5) + 測定加点)
測定加点 = 精密測定器を使用した場合5、なければ0
付与伝達率 η = (Q / 100) * (1 - R / 100)
最終付与量 = 同じ術式の基礎効果量 * η
```

品質基準／上限はH=45/75、F=55/85、M=60/85、I=75/95、X=90/100。Mは熟練で品質と残留の両方が改善する。Xは必須設備の精密測定器により最低Q95から始まり、技能余裕25でQ100へ到達する。

「科学加工ならエンチャントがフルに乗る」はR=0で残留による減衰がないこと。加工が粗ければQによる損失は残る。Q100かつR0で初めて基礎効果量の100%が乗る。

| 付与段階 | 必要エンチャントLV | 必要Q | 必要技術 | 特徴・発展性 |
|---|---:|---:|---|---|
| E1 | 20 | 20 | K06 | 単純な刻印・短い術式 |
| E2 | 60 | 40 | K06 | 安定した単属性・持続付与 |
| E3 | 120 | 60 | K09 | 複数作用の干渉を制御 |
| E4 | 180 | 80 | K09 | 高密度の複合術式 |
| E5 | 240 | 95 | K12 | 精密刻印機を使う最終段階 |

Rが高くても付与段階そのものを追加で禁止しない。Q・技能・技術で段階を判定し、Rは効果量へ掛ける。二重の厳しい罰を避け、画面には「付与可、ただし伝達率○%」を表示する。魔法加工Q上限85のためE5は到達できない。高度な刻印だけを後付けする場合も、母材のQ不足・残留は引き継ぐ。

## 7. 製作・発見・更新の遊び

プレイヤーは、素材を見つける→加工不能の理由を調べる→設備や術式を探す→試作品で実証する→製品化する→付与の限界を知る、という循環を進む。

不成立の原因は「技能不足」「設備不足」「未発見技術」「未知レシピ」「素材不適合」「この経路では不可」を別表示する。事前判定で不成立なら希少素材を消費しない。研究試験で失敗が必要な場合は、量と回収率を先に提示した試料だけを使う。

同じ低級品を大量製作するだけでLV300になる運用は避ける。技能経験は挑戦域で得られ、既習品の反復は経済活動として残す。初回発見は観察・試料比較・測定で確定し、低確率ドロップだけにはしない。

鍛冶職人、魔法成形師、機械工、付与師、鑑定商を分業可能にする。高級設備を所有できない段階では貸工房・都市への発注・部品購入が解決策になる。全技能を一人で最大化することを要求しない。

## 8. 価値と称号

状態、意匠、作者、流通、来歴、製法、伝承を区別する。同じ性能でも、有名工房の刻印、由緒の証明、精密な仕上げ、地域の需要で取引価値が変わる。価格式は保留し、鑑定結果に「確認済みの製法」「伝聞の来歴」「残留測定値」を表示する案とする。

称号は先に好きなものを選んで性能を付ける仕組みにしない。製法や意匠は製作結果から、作者や来歴は記録から、傷みは使用状態から付与する。元辞典のカテゴリ条件を満たしていても、その称号の事実が未成立なら製作時には付けられない。「神に授けられた」などはレシピだけで量産しない。

## 10. 実在技術を参照する際の境界

硬度だけで加工可否を決めず、融点、脆さ、工具、熱処理、組織、形状も障害として扱う。タングステン金属と炭化タングステンは別物として登録する。タングステンは「人間には絶対に鍛造不可能」ではなく、粉末冶金や適切な工業条件下の加工へ進む素材とする。Planseeは粉末冶金から圧延・鍛造・切削などへ進む工程を紹介している。[Plansee 100周年資料](https://www.plansee.com/100/content/Plansee_100Jahre-Festschrift_EN.pdf)

高硬度材や耐熱合金の切削は工具と加工条件が重要になる、という発見の発想を取り入れる。ゲーム内のLVや異相工具は独自設定であり、資料から導いた数値ではない。[Sandvik Coromant：高硬度部品の旋削](https://videos.sandvik.coromant.com/hard-part-turning-for-transmission)
