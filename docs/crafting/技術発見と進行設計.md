# 技術発見と進行設計

共通仕様は[[クラフトシステム設計]]、設備名は[[加工工程プロファイル]]を参照。以下のLV帯は初回接触の目安であり、キャラクターLVによる強制解放条件ではない。技能・設備・知識を揃えた先行者や、交易で技術を導入した都市は順番を飛び越えられる。

## 発見の単位と進捗

技術は「手掛かり→仮説→比較試験→実証→共有」の5状態で管理する。手掛かりだけで完全な製法は得られないが、必要設備と次の試験は提示する。

| 手段 | 得られるもの | ゲーム上の使い道 |
|---|---|---|
| 観察・分解 | 工程の手掛かり | 素材を壊さず候補を絞る。分解は事前に回収見込みを表示 |
| 工房の依頼 | 部分的な知識・設備利用権 | 自前設備がない職人の進行 |
| 古文書・遺構 | 設計図・誤った仮説を含む記録 | 実証によって再現性を確認 |
| 商人・職人との取引 | 教本、試料、加工済み部品 | 戦闘をしない進行経路 |
| 生態の調査 | 温度・粘性・結晶・再生などの着想 | モンスター固有素材を強制しない発見 |
| 比較試験 | 技術ノードの実証 | 同条件で一要因だけ変え、測定結果を得る |

レシピは加工品IDに紐付く。初歩品はK01と一緒に配布してよいが、540品がK01だけで全部解放される扱いにはしない。高度な構造は設計図・実物測定・師匠から学ぶ。製作判定器にはレシピ取得済みを明示的に渡す。

## 設備の循環依存を避ける

最初の旋盤を作るのに、その旋盤でしか作れない部品を要求しない。K07の基準尺と軸受は鍛冶品を手で擦り合わせた低精度版から始める。K08はその低精度旋盤で交換部品を作り、次の世代の機械を改良する研究で成立する。

最初の超硬工具は、精密研削機を要求しない焼結素材と粗研削で作る。最初の異相工具は研究所の借用・購入・粗い試料切削のいずれかで入手できる。K12の精密測定器はK11設備で作れる校正用部品と外部基準器を使って完成させる。最初の神造加工設備には神造材製の必須部品を要求しない。

この「設備用レシピ」は一般の武器防具レシピと別管理にする。今回の工程型Xを、X設備を作るための全工程に再帰的に適用しない。設備用BOMの細目は次の実装段階で追加する。

## 経済と地域差

魔法都市では難素材の成形品が早く流通するが、残留ゼロ品は希少になる。工業都市では同じ素材をより安定して供給でき、付与師が集まる。辺境では高度な仕上げより修理しやすさ・燃料・運搬性が重視される。

商人は、難素材を運ぶ、地方で余る試料を研究都市へ売る、旧式設備を新興工房へ売る、残留測定の証明書を付ける、といった仕事を持てる。熟練魔法品は工場不要・現地対応という利点を残し、科学加工が普及しても完全に市場から消えない。

同じ見た目でも「初学者の魔法成形」「熟練者の魔法成形」「機械で全工程を加工」を履歴で区別する。鑑定前は由来が不明な場合があり、売値の断定をしない。称号の真偽と加工経路の測定結果は別項目にする。

## 調整の観測項目

- 各技術の初発見までの冒険・交易・研究回数。必須ボスで滞留していないか。
- 魔法の閾値直後／余裕30／余裕60での製作品の採用率。
- 素材優位の魔法品と、低残留の旧来素材品が両方選ばれるか。
- 設備代を回収できる受注量と、貸工房の利用率。
- LV300で作れない組合せが、説明可能な難形状に限られるか。
- 低級素材、修理可能品、通常の松明が終盤でも役割を持つか。

初回調整は、品質上限→残留下限→熟練幅60→消費倍率3→設備費の順に一項目ずつ変更する。戦闘性能が未確定のうちは「この素材が絶対最強」と固定しない。目的は過渡期ごとに選択肢が生まれることである。
