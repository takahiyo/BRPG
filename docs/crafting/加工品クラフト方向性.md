# 加工品クラフト方向性

関連：[[クラフトシステム設計]]・[[加工品名辞典]]・[[加工工程プロファイル]]

[[加工品名辞典]]のP0001〜P0540に対応する追加設計表。元の品名・ID・素材指定・出現帯は変更しない。設計方向は用途と形状を成立させる工作上の要点、フレーバーはその道具に残る暮らしや製作者の痕跡を示す試案であり、数値性能や確定した史実を表さない。

形状加算LVは形状・部品点数・摺合せ・反復組立に由来する負担（0〜30）のみ。素材自体の加工難度、入手LV、ドロップLVや元辞典の適正LVとは別に扱う。具体的な製作は各行の工程型から[[加工工程プロファイル]]を引き、選んだ素材の製法ルートと組み合わせて判定する。同じ槍でも木の柄の削り出しと難加工金属の穂先では必要な設備・工程が異なる。

成長の方向は、手加工で構造を覚え、鍛冶・窯・縫製など素材に応じた設備加工へ進み、難加工素材では魔法成形を利用し、最後に機械・科学的な精密成形と付与を組み合わせるものとする。魔法成形に由来する残留魔力は後のエンチャントを阻害するため、熟練による低残留化と、非魔法成形を選ぶ余地を残す。布・革・縄を鍛造へ置換する意味ではなく、織る・裁つ・縫う・撚る工程を保ったまま設備と精度を発展させる。各行の主工程型は一つだが、副部品には別工程を組み合わせられる。
