# 素材加工特性

関連：[[素材LV辞典]]・[[加工工程プロファイル]]・[[クラフトシステム設計]]・[[技術発見と進行設計]]

素材265件のID・素材名は[[素材LV辞典]]のID・表示名と一対一に対応する。同じ名に近い別IDも統合しない。素材カテゴリと適正LVは元辞典を参照し、本表には重複定義しない。方向性と各一文はBRPG独自の描写案であり、原典の作品設定や実在素材の工学仕様を確定するものではない。

## 経路と在庫の読み方

Hは手工・切削・編組・低温成形、Fは炉・鍛造・鋳造・焼成、Mは魔法による直接成形、Iは動力機械加工、Xは精密科学加工。値は素材を扱い始める必要技能LVで、出現LVとは別。`-` はその経路では実行不可。技能300でも解禁されない。素材の値だけで完成品を作れるわけではなく、必要技能は `max(本表の経路LV, 工程型の経路LV) + 形状加算LV` で判定し、レシピ・技術・設備もすべて満たす。設備と追加技術は[[加工工程プロファイル]]を参照する。Hの存在は、手工具による許可された部品加工の入口を示し、あらゆる形状・素材合成を手工だけで行える意味ではない。

原則として加工用の塊・板・棒・布などの在庫を想定する。鉄鋼のFは鍛造・鋳造・熱処理など素材に適した工程を選び、すべての鉄鋼材を同じように槌で鍛える意味ではない。軟質金属は本表の設備上の工程区分であり、実在の硬度順位を保証しない。高融点金属・難削合金のFを閉じた行は、初期の温度管理炉では扱わず、Mまたは専用工業設備へ進む設計とする。宝石結晶は普通の宝石・硬い石・固体の異相結晶を支えて加工する区分で、すべてを宝飾品としてのみ使う指定ではない。

鉱石原料は鉱物を主材とする装飾祭具・計量記録にのみ使用し、金属部材には先に別レシピの精錬・精製・合金化が必要。鉱石から金属への変換を本表のMなどで省略しない。工業繊維複合のHは既製布の裁断・縫製や硬化済み板の切り分けを表し、繊維合成・樹脂合成・積層硬化の技術を不要にはしない。繊維皮革の革はなめし済み、布・糸・紙は加工用在庫を想定する。陶磁は成形可能な調製済み原料を在庫単位とし、焼成工程をFで行う。完成した陶片を手で貼るだけの例とは区別する。

エネルギーは液体・気体・流動魔力・保持条件未確定の超常試料をまとめた保留区分であり、物理学的な同一分類ではない。主材経路はすべて`-`とし、封入等の副材レシピが定義されるまで完成品の主材にはできない。アンオブタニウム・ニュートロニウム等の実体未確定材も初版ではこの保留区分とする。スタルリムとエーテリウムは、この表では固体の加工用結晶在庫として扱うBRPG案を採用する。神造固体のIは使えず、Xには専用の異相制御技術も必要となる。

## 魔法残留の扱い

魔法残留R0はMを最低技能で行ったときの基準値（0〜100）。素材固有の魔力親和性や内在エネルギーそのものではない。Mが存在しない保留行のR0=0は、加工可能・魔力なし・安全などを意味せず、現在計算対象の魔法成形がないことを示す。

実際の残留は[[クラフトシステム設計]]に従い、技能余裕0ではR0、余裕30ではその中間、余裕60以上では `ceil(R0 / 3)` まで減る。製作閾値を満たしていても余裕が乏しい間は消費魔力と残留が多く、後のエンチャントの発展性を抑える。魔法加工の熟練でも残留はゼロにならず、Mの品質上限も残る。新規のH/F/I/Xは加工由来の残留を生まないが、既存の魔法加工部材を再利用すれば履歴を引き継ぎ、磨き直しや改名では消えない。
