# モンスター画像の利用方針

今後の新規生成は、名前なし・透明背景・5列×6行の30枠へ変更する。固定指示は[[アセットシート共通プロンプト]]、入力リストは[[モンスター画像生成リスト_30枠]]を参照。以下の5×8・40体対応は、既存画像だけの仕様として残す。新旧シートの列数・行数・ID範囲を混用しない。

ルートの `幻想モンスター図鑑 40種.png` を確認。画像サイズ992×1586ピクセル、5列×8行で、[[モンスター辞典_LV001-150]]のM0001〜M0040と左上から行優先の順番で対応する。元画像は変更しない。

## 一枚のまま使う

個別ファイルへの切り分けは必須ではない。モンスターIDから行・列または表示矩形を引き、一枚の画像の該当部分だけを表示するスプライトシートとして使える。図鑑、遭遇カード、編成候補、戦利品報告などのサムネイルに向く。

```text
index = モンスターIDの数値 - 1       # M0001〜M0040に限定
column = index % 5                  # 0〜4
row = floor(index / 5)              # 0〜7
```

これは今回のシートに対する割当だけで、将来の画像をID順に固定する規則ではない。本実装では `monster_id -> sheet_id, rect` の対応表を持たせる。M0041以降はこの画像にはなく、仮アイコンなどへフォールバックする。

## 表示上の調整

まず各枠をそのまま切り出して表示する。全体寸法が5・8で割り切れないため、等分座標を丸めた初期矩形を作り、枠線の位置に合わせて端を微調整する。生成画像の罫線は厳密なグリッドを保証しない。隣枠が見える場合は個別矩形の内側へ数ピクセル寄せる。

名前は画像へ焼き込まれている。称号付きモンスターへ流用する場合は、文字欄を除く表示矩形を設定し、正式名・称号・脅威度LVはUIで表示すると管理しやすい。文字を隠す範囲で足先などが欠けないか、各セルを確認する。背景と枠線も残るので、透明な戦闘スプライトとしてそのまま動かす用途には向かない。

個別PNGに分ける利点は、画像を一体ずつ差し替える・外部ツールへ渡す・一部だけ読み込む運用が簡単なこと。一枚のままなら、現在の画像をすぐ採用でき、ファイル数も増えない。表示用矩形は元画像を破壊せず変更できるため、今はシートのまま使い、必要になったときに個別化してよい。

この資料は利用方針とID対応の記録であり、ゲーム画面への組込みや画像分割はまだ実施していない。
