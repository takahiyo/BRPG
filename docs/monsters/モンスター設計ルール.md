# モンスター設計ルール

**基礎モンスター400件＋称号160件**を用意し、LV1〜300の遭遇候補を作る。今回は名前・脅威度LVと、組合せ制御に必要なカテゴリ・特性だけを持つ。HP、攻撃力、報酬、行動は後から考える。LVの共通方針は[[LV設計ルール]]。

## 30LV刻みの基準

| LV帯 | 基準モンスター | 基準LV | 帯内の基礎候補数 |
| --- | --- | --- | --- |
| 1〜30 | オーガ | 30 | 40 |
| 31〜60 | ミノタウロス | 60 | 40 |
| 61〜90 | ワイバーン | 90 | 40 |
| 91〜120 | ヒュドラ | 120 | 40 |
| 121〜150 | 成竜 | 150 | 40 |
| 151〜180 | リッチ | 180 | 40 |
| 181〜210 | エルダードラゴン | 210 | 40 |
| 211〜240 | クラーケン | 240 | 40 |
| 241〜270 | 古竜王 | 270 | 40 |
| 271〜300 | 終焉竜 | 300 | 40 |

各基準は帯の上端に置いた比較用の代表であり、別種との相性や戦闘の勝敗を確定するものではない。LV1の入口にはスライムを置く。基礎種は[[モンスター辞典_LV001-150]]・[[モンスター辞典_LV151-300]]、称号は[[モンスター称号辞典]]、生成結果の例は[[モンスター生成例1200]]を参照。

一般的なファンタジー・ゲームの呼称、神話や伝承の存在、日本の妖怪、独自の生態・属性亜種を混ぜた候補集。固有の神話名は種族名に限らず遭遇名として扱う。妖精・天族・神霊を含め、掲載は敵対や邪悪さを意味しない。LVと分類はこの企画の仮設定であり、各作品の公式序列の転載ではない。

## 種族カテゴリ

1体につき下記の主カテゴリを1つ持つ。たとえば海にいる竜は「竜」＋特性「水」、蛇の下半身を持つ亜人は「亜人」＋特性「蛇体」とし、棲息地や身体の特徴を別軸にする。

| 種族カテゴリ | 主な対象 |
| --- | --- |
| 亜人 | コボルト、ゴブリンなど人型の知的種族 |
| 獣 | 哺乳類や獣型の魔獣 |
| 鳥 | 鳥型の生物・魔鳥 |
| 爬虫 | 蛇、蜥蜴など。竜として扱うものは竜に分類 |
| 水棲 | 魚、軟体動物、海獣などを主とする分類 |
| 虫 | 昆虫、蜘蛛、節足動物などの便宜的な集合 |
| 植物 | 植物、菌類、根や花の怪物 |
| 粘体 | スライム、ウーズ、流体状の怪物 |
| 不死 | 死体、骨、亡霊などのアンデッド |
| 精霊 | 自然・属性に結び付いた存在 |
| 妖精 | 妖精や妖精的な怪異 |
| 竜 | 竜、ワイバーン、竜系の魔獣 |
| 巨人 | オーガや神話的巨人 |
| 魔族 | 悪魔・魔界の存在 |
| 天族 | 天使・天空に結び付いた存在 |
| 造物 | ゴーレム、魔導機構、動く人工物 |
| 異形 | 上記に収まりにくい異質な怪物 |
| 神霊 | 神格・神話的霊獣・神の現れ |

これらは生成条件のためのゲーム内分類。生物学や宗教・伝承の厳密な分類と一致させるものではない。

## 特性タグ

| 軸 | 許可するタグ | 用途 |
| --- | --- | --- |
| 身体 | 肉体、筋骨、甲殻、鱗、毛皮、翼、蛇体、無形、霊体 | 形や構造に合う称号を選ぶ |
| 役割 | 知性、軍制、術者 | 階級、武技、魔術に合う称号を選ぶ |
| 成長・時代 | 幼体、成体、古代 | 年齢や由来に合う称号を選ぶ |
| 属性 | 炎、氷、雷、水、風、土、毒、闇、光 | 既にその性質を持つ種に属性称号を付ける |

特性は名前の適合を判定する情報で、具体的な耐性や技能値は定めない。未記載の特性は「持つ」と推定しない。「古代」は古い存在・由来を持つ設計タグで、具体的な年齢は別途決める。

`筋骨` は筋肉・骨格の発達に関する称号を付けられるもの。粘体、霊体、無形には付けない。`軍制` は組織的な軍階を置く文化・所属があるという設定。知性や群れだけを理由に付けない。この案ではコボルト、ゴブリン、ホブゴブリン、オーク、ノール、リザードマンに軍階を持たせ、ほかは明示的な兵団などに付けた。竜には軍制を付けない。

術者は意思を持って術を扱う役割として知性も付ける。単に炎を吐く種は属性「炎」だけでよく、自動的に術者にはしない。基礎種の成体は通常個体、幼体を示す名前は幼体として設定する。両方を同時に付けない。

## 称号の照合

```text
対象種族に一致（対象列内はOR。*なら全種族）
AND 必要特性を全部持つ（AND）
AND 除外特性を一つも持たない
AND 完成LVが1〜300
AND 完成LVが称号の適正LV範囲内
```

| 組合せ | 判定と完成LV |
| --- | --- |
| ありふれた＋コボルト | 可。10＋0＝LV10 |
| 屈強な＋コボルト | 可。10＋8＝LV18 |
| ジェネラル＋コボルト | 可。10＋35＝LV45 |
| 屈強な＋スライム | 不可。種族・筋骨条件を満たさない |
| ジェネラル＋成竜 | 不可。対象種族と軍制条件を満たさない |
| 濃縮された＋スライム | 可。1＋8＝LV9 |
| 濃縮された＋コボルト | 不可。粘体ではない |
| 終焉竜に正の補正 | 不可。基礎LV300を超える |

固定LVの基礎種と、称号で作る派生個体を区別する。称号付き候補は基礎種の元の30LV帯を越えてよい。「ジェネラルコボルト」はLV31〜60帯の候補になる。完成LVを基準に出現帯を選ぶ。

## 名前とLVを抽選する

BRPGフォルダでPython 3から実行する。追加ライブラリ不要。

```powershell
python scripts/generate_monster_names.py --min-level 31 --max-level 60 --count 40 --seed 19
python scripts/generate_monster_names.py --monster コボルト --title ジェネラル --count 1
python scripts/generate_monster_names.py --category 粘体 --min-level 1 --max-level 30 --count 20
python scripts/generate_monster_names.py --level 180 --count 5 --seed 19
```

通常は基礎種と適合する称号付き個体が候補になる。`--title` を指定するとその称号付きだけ、`--base-only` は基礎種だけ、`--no-base` は称号付きだけ。`--monster` と `--title` は名前の完全一致で複数指定可。`--with-ids` は元の基礎種ID・称号IDも表示する。

出力は名前と脅威度LVのMarkdown表。同じ候補名を重複抽選しない。指定数が候補数を超えるとエラーを返す。固定seedは同じ辞典と引数で再現できるが、辞典の並びや値を変えると結果も変わりうる。サンプル表は生成時点の固定出力なので、辞典更新後は作り直す。

## 着想・照合に用いた資料

- [Paizo / Pathfinder：Monsters by Type](https://legacy.aonprd.com/bestiary/monstersByType.html)：竜、粘体、造物、植物などを別カテゴリで扱う分類や一般的な怪物名の参考。
- [Theoi：Greek Bestiary](https://www.theoi.com/greek-mythology/bestiary.html)：ヒュドラ、キマイラ、巨人や合成獣などの神話名と系統の参考。
- [『スノッリのエッダ』英訳](https://www.gutenberg.org/ebooks/18947)：フェンリル、ヨルムンガンドなど北欧伝承の着想元。
- [国際日本文化研究センター：川天狗の伝承記録](https://www.nichibun.ac.jp/cgi-bin/YoukaiDB3/youkai_card.cgi?ID=0450014)：河童と川天狗の地域呼称の例。別表記や呼び名の違いを別種として無制限に水増ししない方針の参考。
- [スクウェア・エニックス：DQX覧会「Three rings of Slimes」](https://www.dqx.jp/Xrankai/number/art01.html)：スライムの派生表現というゲーム上の着想の参考。

資料から名前・モチーフ・分類の幅を参考にし、数値や説明文は再現していない。基礎辞典の独自亜種や高LVの創作名について、これらの資料の公式登場名とは主張しない。
