# モンスター称号辞典

160件。[[モンスター設計ルール]]のカテゴリ・特性と照合する。[[モンスター辞典_LV001-150]]・[[モンスター辞典_LV151-300]]の基礎脅威度にLV補正を足し、完成したモンスターの脅威度がこの称号の適正LV範囲に入る場合だけ採用する。全体の共通方針は[[LV設計ルール]]を参照。

条件の `*` は全種族、`-` は特性条件なし。対象種族のカンマはOR、必要特性のカンマはAND、除外特性のカンマはOR。すべての列の条件を同時に満たす。称号は接続語込みでそのまま名前の前に付ける。全LV・補正はBRPG用の仮配置。
