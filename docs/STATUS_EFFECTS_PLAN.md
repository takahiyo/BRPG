# 状態異常・バフ・回復手段の開発計画

2026-10-22追加要件。**この文書は未実装の計画**。ユーザー指定の効果を必須要件とし、数値・候補名・補足ルールは提案と区別する。実装段階と検証条件は [開発計画](../DEVELOPMENT_PLAN.md) のS0-S5を参照する。Obsidian原資料、既存の辞典ID、現行セーブをこの計画追加で変更しない。

## 1. 現行から変更する契約

| 対象 | 現行コード | 新要件として実装する内容 |
| --- | --- | --- |
| 毒 | `poison` 残ターン、戦闘ターン末のダメージ | 対象の行動ごとにダメージ。猛毒を別効果として追加 |
| 気絶 | MP0の表示名、MP回復で行動再開 | VIT依存の一定時間行動不能。MP0とは独立 |
| MP0 | `alive()` の戦闘参加条件から除外 | マナ枯渇と命名。MP回復で行動再開、全快までINT系後遺症 |
| SP0 | 能力半減、歩行遅延。戦闘行動は可能 | SP枯渇としてSP回復まで行動不能。全快までVIT系後遺症 |
| LIFE0 | 死亡、通常回復薬では回復不可、蘇生手段あり | 致死としてLIFE回復まで行動不能。回復しても全快まで全能力後遺症 |
| 状態表示 | 死亡/気絶/疲弊/毒の優先表示 | 複数状態、残り時間/重複数/強度、後遺症、解除条件を別々に表示 |
| 敵対化 | 敵とパーティーが固定的に分離 | 混乱・誘惑は戦闘内の行動/陣営変化、操屍は永続的な所属移動 |

これは意図した仕様変更であり、SP0を旧来の半減だけで済ませたり、MP0を新しい気絶として流用したりしない。旧保存の値と装備・英雄IDを保全し、表示・戦闘・探索・施設・クラウド保存を同じ定義へ移す。

## 2. 必須の状態異常一覧

以下の20種類を開発対象へ登録する。「解除手段」は実装候補で、効果量・価格・習得条件は後で確定する。通常治療と専用治療を区別し、何でも解ける安価な万能薬にはしない。

| 状態 | 必須の効果・持続 | 回復/対処の計画 |
| --- | --- | --- |
| 毒 | 行動ごとの継続ダメージ | 解毒薬・解毒術。既存の毒を移行 |
| 猛毒 | 行動ごとの大きな継続ダメージ | 強解毒薬・上位解毒術。毒との併存/上書きはS0で確定 |
| 麻痺 | ランダムに行動を阻害 | 抗麻痺薬・神経回復。行動阻害率を明示 |
| 気絶 | 一定時間行動不能、VIT依存 | 時間/回復判定・覚醒手段。高VITほど短くなる案を検討 |
| マナ枯渇 | MP0で行動不能。MP回復後も全快までINT系にデバフ | 魔力薬・魔力回復術・宿。行動再開と後遺症解除を区別 |
| SP枯渇 | SP0で行動不能。SP回復後も全快までVIT系にデバフ | 携帯食・活力術・休息。行動/歩行/SP消費経路を統一 |
| 致死 | LIFE0で行動不能。回復後も全快まで全ステータスにデバフ | 蘇生薬・蘇生術・神殿。どの回復がLIFE0を対象にできるかは別途確定 |
| 混乱 | 一定時間ランダム行動、同士討ちあり | 鎮静薬・精神安定術。対象範囲・陣営・射程・消費を再判定 |
| 誘惑 | 一定時間敵対行動、エネミーとして行動 | 誘惑解除・精神防護。解除後は元の所属へ戻す |
| 操屍 | 致死者がアンデッド化、永続的敵対、離脱して同ダンジョンの徘徊敵に | 専用対抗手段。原則は再度倒して死体回収、高額蘇生。第5節参照 |
| 痺れ | 攻撃力・回避力を低減 | 神経回復・抗痺れ薬。確率行動阻害の麻痺とは別 |
| 睡眠 | 被ダメージまで気絶相当の行動不能、重ね掛け可。睡眠中は誘惑等の精神異常への抵抗が大幅低下 | ダメージ・目覚まし薬・覚醒術。重複時の覚醒単位はS0で確定 |
| 束縛 | 糸などによる行動阻害、時間経過では解除されない | 切断・脱出・解縛術・対応道具。戦闘終了や移動で勝手に消さない |
| 火傷 | 炎熱系の継続ダメージ、時間解除には長くかかる | 冷却薬・治癒術・炎熱耐性。火傷の発火タイミングはS0で確定 |
| 虚弱 | SP消費が倍加 | 活力回復・虚弱解除。通常攻撃/技/歩行等のSP消費に漏れなく適用 |
| 頭痛 | MANA消費が倍加 | 鎮痛薬・精神治癒。戦闘外の魔法/製作を含むMP消費も監査 |
| 脆弱 | LIFE消費が倍加 | 生命安定・脆弱解除。「LIFEを支払うコスト」と被ダメージを混同しない |
| 病 | 全体的な能力デバフ。強度により重病 | 治療薬・治療術・施設。強度と進行/回復を記録 |
| 不治の病 | 永続的な能力デバフ。入手難度の高い回復手段あり | 希少薬・高度治療・特別依頼。「不治」を回復不能とは扱わない |
| 伝染病 | 病の変種、確率でパーティー内へ感染拡大 | 治療に加えて隔離・予防薬。感染判定間隔と伝播範囲を設定 |

## 3. 共通効果基盤と安全性

- 状態定義の正本に、分類（身体/精神/疾病/呪い等）、強度、持続の種類、重複規則、抵抗、発火タイミング、解除タグを置く。実体には対象ID・付与元・残量等を保持する案とし、同じ計算をUI/AI/施設に複製しない。
- 生存・戦闘参加・操作可能・敵対・対象可能・探索同行を分離する。単一の `alive()` だけで「眠っているので攻撃対象から消える」「全員気絶した瞬間に即ロスト」「誘惑者に味方の指示を出せる」といった誤判定を作らない。
- 毒/猛毒は全体ターン末ではなく対象の行動機会に接続する。麻痺/睡眠等で行動できなかった機会、追加攻撃/反撃、道具、逃走、探索歩行をどう数えるかをS0で確定し、二重ダメージや行動スキップによる永久停止を防ぐ。
- 一定時間効果は戦闘と探索の時間単位を定義してから実装する。ターン換算/ゲーム内時間連動は設計案であり、現実の待ち時間やブラウザ非表示中に勝手に進むものとはまだ決めない。束縛・不治の病・操屍等の永続効果には自動期限を付けない。
- 回避力への効果は、命中/回避の計算自体を先に用意する。痺れをAGI低下だけで代替しない。INT系/VIT系/身体系の対象能力・派生値を正本で列挙し、名前の印象だけで別々に判定しない。
- 0到達イベントで枯渇/致死の後遺症を記録し、少量回復だけでは解除しない。宿・道具・魔法・レベルアップ・装備変更・読込のすべてに同じ全快判定を適用する。
- 最大MP/SP/LIFEへのデバフで全快境界が下がって即解除される循環を防ぐ。後遺症を除く最大値で判定する案をS0で検証し、装備の着脱や成長による不正解除も試験する。補正を出生能力/成長配分へ直接書き戻さない。
- 消費倍率は消費確定時に一度だけ適用。虚弱/頭痛/脆弱と軽減バフを同じ経路で計算し、表示/入力可否/自動判断/実消費を一致させる。HPを支払う技で自傷致死を許すか、自動行動が枯渇直前まで使うかも明記する。
- 睡眠の重複、被ダメージ覚醒、精神抵抗低下、混乱/誘惑の優先順位は独立テストにする。解除された効果で再び解除イベントを起こす無限連鎖や、1回の攻撃で重複回数分の感染を起こす状態を防ぐ。
- 部分回復と解除を分離し、汎用 `cleanse`/宿/全滅/転職で永続病や後遺症まで一括消去しない。状態中に操作可能者がいない場合の待機・回復・撤退/搬送を用意し、コマンド入力待ちで進行不能にしない。
- 新しい保存項目の型・範囲・効果ID・重複数・所属参照を検証する。旧 `poison` を一度だけ変換し、ロード/クラウド再試行で二重発火させない。追加項目のない旧保存の互換性、退避、保存し直して再読込を確認する。

## 4. 対になるバフと追加異常の候補

以下は**採用候補**。単なる状態の解除、付与前の耐性、効果中の軽減、能力強化を区別する。永続病/操屍の解除は専用手段を必要とし、通常バフで無条件に消さない。

| バフ候補 | 効果の方向性 | 対応する異常・用途 |
| --- | --- | --- |
| 解毒耐性/抗毒障壁 | 毒・猛毒の付与抵抗/継続被害軽減 | 毒・猛毒対策。解毒そのものとは別 |
| 神経活性/堅忍 | 麻痺抵抗、痺れ軽減、気絶からの回復補助 | 身体系行動阻害 |
| 精神防壁/明鏡 | 混乱・誘惑抵抗、睡眠中の精神抵抗低下を緩和 | 精神異常。完全免疫は上位候補 |
| 不眠/覚醒維持 | 睡眠付与抵抗、睡眠重複の抑制 | 睡眠対策 |
| 自由行動/解縛守護 | 束縛付与抵抗や脱出補助 | 束縛対策。既存束縛の解除とは別 |
| 耐熱/冷却膜 | 炎熱耐性、火傷ダメージや持続の軽減 | 火傷対策 |
| 再生/生命循環 | 行動/時間ごとのLIFE回復、LIFE消費軽減 | 脆弱対策。LIFE0の蘇生は含めない |
| 魔力循環/集中 | MANA回復、MANA消費軽減、INT系能力強化 | 頭痛・マナ枯渇への備え |
| 活力/持久 | SP回復、SP消費軽減、VIT系能力強化 | 虚弱・SP枯渇への備え |
| 加護/生命保護 | 致死回避や蘇生後の回復補助を持つ上位効果 | 致死対策。発動回数/消費を制限する案 |
| 健康/免疫/防疫結界 | 疾病抵抗、感染確率低減、悪化抑制 | 病・重病・伝染病 |
| 聖別/魂の庇護 | 操屍への抵抗、遺体保護、浄化支援 | アンデッド化対策。完全解除は専用技能側 |
| 再生医療/肉体修復 | 身体欠損の回復を補助 | 高度・希少な恒久損傷治療。通常リジェネと区別 |
| 剛力/俊敏/精密/守護 | 攻撃・回避・命中・防御を強化 | 能力デバフと相互作用する汎用強化 |

追加の状態異常案として、出血（身体系継続被害）、沈黙（詠唱阻害）、暗闇（命中/視認低下）、恐怖（行動選択/接近制限）、呪い（回復効率低下等）、凍結/鈍足（行動順/移動阻害）を検討する。これらは必須20種とは別枠で、固有の対処手段・敵の予告・既存効果との差別化を説明できるものから採用する。

## 5. 操屍・徘徊敵・回収・隠し進化

必須のライフサイクルは「致死した探索者 → 操屍/離脱 → 元ダンジョンの徘徊敵 → 討伐 → 死体回収/持帰り → 通常より高額な蘇生」。専用スキル/アイテムによる対抗経路も設けるが、基本経路を置き換えない。

- 敵対化を一時的な誘惑の延長で扱わない。参加枠から外し、英雄IDを保った追跡記録に移し、元パーティー・控え・敵・回収死体のいずれか一つだけが所有する。装備/所持品/経験/成長配分/身体損傷/進化を同じ英雄へ紐付ける。
- 徘徊先は生成し直した別地図ではなく、元のダンジョン識別子（必要なら階層/位置）で保存する。再入場/撤退/全滅/ロードをまたいで遭遇でき、地域再生成で消失しないよう検証する。
- 遭遇時は元探索者の能力・装備とアンデッド補正から敵データを組み立てる。再度LIFE0へして死体へ移し、討伐報酬と所持品を二重取得できないようにする。死体を持ち帰る操作、搬送枠/重量、持帰り前の再全滅も仕様化する。
- 神殿等で通常より高い費用を提示し、持帰った死体を蘇生する。名簿満員・編成枠満員でも死体や英雄を捨てず、復帰待ちを扱う。貧困時の回収/高額蘇生が進行不能を生まない経済設計を別途検証する。
- 長時間放置による「滅亡」「深刻な身体欠損」「進化」の確率イベントを持たせる。滅亡した場合はロスト。永久削除/ロストは通常致死や単なる全滅と区別し、誤発火を防ぐ。
- 身体欠損は身体系能力の恒久的な低下として記録する。ただし高度な回復スキル・魔法・希少アイテムで回復できる。元の成長値を破壊せず、損傷補正を解除可能にする。
- 低確率の進化を複数段階で管理し、最終的に真祖/不死者の王へ到達し得る設計にする。段階・分岐・条件・保持可能な強化は未確定。進化個体を倒して蘇生できた場合、強化された能力を保持して復帰できる隠し経路を用意する。
- 隠し進化の未発見段階・確率・最終到達先は通常UI/手帳/通知へ露出させない。実装用仕様は通常配布アセットと分離し、表示は遭遇/発見に応じて開示する。
- 放置判定はゲーム内経過時間を基準とする案。現実時間/オフライン中の進行は未確定とし、再読込/時計巻戻し/クラウド競合/リトライで判定を重複しない。実装前にロストまでの猶予・警告・確率・判定上限を確定する。

## 6. アイテム・魔法・スキルへの接続案

| 系統 | アイテム例 | 魔法/スキル例 | 配置・獲得の計画 |
| --- | --- | --- | --- |
| 基本治療 | 解毒薬、強解毒薬、抗麻痺薬、目覚まし薬、冷却薬 | 解毒、神経回復、覚醒、解縛 | 商店/調合/僧侶・薬師等。序盤異常には序盤の対策を用意 |
| 資源回復 | 魔力薬、携帯食、生命回復薬 | 魔力還流、活力付与、治癒、蘇生 | 現行の回復/宿/神殿へ接続。資源回復と後遺症解除の表示を分離 |
| 精神治療 | 鎮静薬、護符、精神防護薬 | 混乱解除、誘惑解除、精神防壁 | 精神/支援系職と装備。睡眠中の抵抗低下も表示 |
| 病気/感染 | 治療薬、予防薬、隔離用品 | 治療、重病治療、防疫結界 | 工房・神殿・治療職、感染地の依頼と採集素材 |
| 高度治療 | 希少な病気治療薬、肉体修復薬 | 難病治療、肉体再生、上位蘇生 | 高位職・高級工房・特別依頼。希少性と回復可能性を両立 |
| 対アンデッド | 聖水、遺体保護具、魂の器 | 浄化、操屍解除、魂の回収、葬送 | 聖職/死霊系・探索回収。専用効果の対象状態を厳密に定義 |
| 付与/戦術 | 毒瓶、煙、粘着糸、罠、バフ薬 | 毒/猛毒、麻痺、混乱、誘惑、束縛、火傷、各種弱体/強化 | 敵・職業・技能・付呪・地形へ少数ずつ接続。全敵に一括付与しない |

名称は候補であり、同名の既存技能/道具を調査して再利用または拡張する。既存133技/22道具や辞典データとの重複登録を避け、ID/定義の正本を決めてから追加する。汎用 `cleanse` には解除可能な分類/強度を持たせ、蘇生・難病・操屍は専用効果へ分ける。

自動行動は付与確率・抵抗・資源倍率・同士討ちリスク・既存の温存/撤退規則を考慮する。回復不能者へ同じ薬を使い続けたり、麻痺による行動失敗で道具だけを重複消費したりしない。支援の優先順位を定義し、混乱/誘惑中はプレイヤーの予約行動より状態の行動規則を優先する。

## 7. 実装前に確定する項目

1. 「行動ごと」と「一定時間」の定義、戦闘/探索/待機/オフラインの進行、睡眠重複時にダメージで何層解除するか。
2. INT系/VIT系/身体系/全ステータスの範囲、後遺症の強度、全快の基準最大値、重複/上限/抵抗/解除の順序。
3. 致死からの回復に通常治癒を認めるか、蘇生専用か。SP0者の移動/搬送、全員が一時行動不能のときの待機/敗北判定。
4. LIFE消費技の自傷致死可否、精神異常の優先順位、誘惑中の死亡/蘇生時の所属、感染の進行と隔離。
5. 操屍の発生源/条件、回収容量/蘇生価格、放置進行・警告・ロスト猶予、進化/欠損の確率と強化保持範囲。

数値未確定を理由に必須効果を省略しない。追加異常/バフは上記契約へ載せられるものから採用し、重大な仕様判断は実装前のS0で記録する。
