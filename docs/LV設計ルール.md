# LV設計ルール

キャラクター、ダンジョン、モンスター、ドロップ品を**LV1〜300**で関連付ける。今回の数値は参考になる仮配置で、戦闘力や経済の調整結果ではない。数値を表から変更して再調整できる構成にする。

## 基準LVと適正LVの役割

| 対象 | 持つLV | 今回の扱い |
| --- | --- | --- |
| キャラクター | 現在LV | 将来のキャラクターデータで1〜300を持つ。今回は個別キャラクターを追加しない |
| ダンジョン | 基準LV、必要なら適正LV下限・上限 | 将来のダンジョンデータで持つ。階層ごとに基準LVを変えられる |
| 基礎モンスター | 脅威度LV | 辞典の固定値。基礎種の適正LVの代表点として扱う |
| モンスター称号 | LV補正、適正LV下限・上限 | 補正後の脅威度LVが称号の範囲に入ることを確認する |
| アイテム称号 | 適正LV下限・上限 | その称号を抽選してよい出現・利用LVの範囲 |
| 素材 | 適正LV下限・上限 | その素材を抽選してよい出現・利用LVの範囲 |
| 加工品 | 適正LV下限・上限 | その品種を抽選してよい出現・利用LVの範囲 |

適正LVは「その範囲で使ったり出現させたりしてよい」という候補制限。装備要求LV、売値、ダメージ倍率、絶対的な強さはまだ定義しない。例えば木・鉄や通常のたいまつは高LVでも使うため、上限300の広い範囲を持てる。素材原典のF〜EXは資料上の区分として残し、既存作品の強さから公式換算したものとは扱わない。

## モンスターの完成LV

```text
完成脅威度LV = 基礎モンスターの脅威度LV + 称号のLV補正
```

完成LVが1〜300に入り、かつ称号の適正LV下限〜上限に入る場合だけ採用する。称号なしなら基礎LVのまま。範囲外を1や300に丸め込まない。複数称号の加算は今回は行わない。

例：コボルトLV10に「屈強な」補正+8でLV18。「ジェネラル」補正+35でLV45。スライムには筋骨・軍制がないため、この2称号は付かない。「濃縮された」ならスライムLV1に+8でLV9となる。

## アイテムの完成適正LV

```text
完成適正LV下限 = max(称号の下限, 素材の下限, 加工品の下限)
完成適正LV上限 = min(称号の上限, 素材の上限, 加工品の上限)
```

下限が上限を超える組合せは採用しない。抽選元のLVがこの共通範囲に含まれ、かつ素材・加工品・称号のカテゴリ条件も一致する場合に候補へ入れる。

たとえば仮に称号がLV20〜180、素材がLV100〜300、加工品がLV1〜300なら、完成品はLV100〜180。抽選LV150では候補になり、LV80や200では候補にならない。範囲を足し算して300を超えることはない。

## ダンジョン・ドロップへの接続案

1. ダンジョンまたは階層に基準LVを設定する。
2. 出現モンスターの完成脅威度LVを、その場所の適正範囲で絞る。
3. 宝箱は階層の基準LV、討伐ドロップはモンスターの完成脅威度LVを抽選元LVにする。
4. そのLVが適正範囲に入るアイテムを、カテゴリ適合も確認して抽選する。

基準LVとの差の許容幅、ボスの補正、ドロップ確率は後から設定する。現在のスクリプトは指定LV・指定範囲で候補を絞るところまでで、ゲーム本体の戦闘・宝箱・ドロップ処理には接続していない。

LV300の場所でも日用品や使い古した品が候補に残りうる。これは広い適正範囲を認める設計によるもの。「候補に入る」と「どれくらいの確率で出る」は分け、上位品を優先する重み付けは調整時に追加する。
