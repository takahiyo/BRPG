# 受領モンスターシートの整理記録

現存14枚だけを整理。元ファイル名の末尾番号ではなく、先頭行の種と制作表の並びを照合した。以下のID範囲は制作リストとの対応候補であり、全セルの名称・配置・透明余白を承認した意味ではない。その後 [実装・検品記録](../MONSTER_ART_INTEGRATION.md) の21体だけを明示矩形でゲームへ登録し、14原本は未検品を含むプレビューとして配信した。制作段階の均等枠manifestとruntimeの矩形承認は区別する。

## 配置と命名

- 配置先：プロジェクト直下。既存画像と `scripts/build-pages.cjs` のルート画像構成に合わせる。メディア統合段階で14枚を配布許可リストへ追加済み。
- 通常名：`monsters_sheetNN_Mxxxx-Myyyy.png`。生成リストの保存名案と一致する。
- 別案：`monsters_sheet14_M0391-M0400_alt.png`。横長の別出力を通常版に上書きしない。
- シート01（M0001〜M0030）は欠番。削除された旧サンプルを復元しないというユーザー選択に従い、推測・複製で埋めていない。
- 全14枚で移動前後のSHA-256が一致。再圧縮・リサイズ・切出し・透過加工はしていない。

## 組込み前の注意

- シート07/10は高さが1px少ない。229pxの正方形セルとしてそのまま機械切出ししない。
- シート14通常版は10体を上部2段へ大きく配置しており、指定の229pxセルに収まる配置ではない。5×6での機械切出しは未承認。
- シート14別案は横長5×2の配置。通常の5×6シートとして登録しない。
- 他のシートも実寸が一致するだけでは使用承認にしない。全セルの対応、切れ・隣セル干渉、外周の色にじみ、透明余白は別途検品が必要。
- 対応するゲーム敵の遭遇70種は別のID群。図鑑用画像を名前の類似だけで敵へ流用しない。
