# マップデザイン・ダンジョンアセットの制作・組込み仕様

現行のマップ描画（`exploration-ui.js` の `draw()` 関数）における Canvas 2D プリミティブ（単色矩形・直線・多角形）による暫定描画を、画像生成によって制作された高品質なファンタジー手描きアセット（壁・床・オブジェクト・トラップ・階段・門）へ置き換えるための正本仕様書。

モンスターアートの制作規格（[MONSTER_ART_SPEC.md](MONSTER_ART_SPEC.md)）と共通のグリッド・寸法契約を採用し、画像生成AIから均等セルで一括生成したのち、検品を経て Canvas 描画エンジンへ接続する。

---

## 1. アセットシートの制作規格

モンスター画像（[受領シート02](../monsters_sheet02_M0031-M0060.png)）と同一の制作規格を採用し、画風・質感・光彩の統一感を保つ。

| 項目 | 規格 | 備考 |
| --- | --- | --- |
| **全体解像度** | **1145 × 1374 px** | RGBA PNG（アルファチャンネル透過） |
| **グリッド配置** | **横 5 列 × 縦 6 行（全 30 セル）** | 左上（1行1列）から右、次行へと連番 |
| **1セル寸法** | **229 × 229 px** | 完全な正方形セル |
| **安全描画領域** | **中央 約 170〜190 px 内** | 各タイルの主要要素を中央に配置 |
| **セル内透明余白** | **四辺 19 px 以上の完全透明** | 隣接セルとの混入・境界切れを完全に防ぐ |
| **背景** | **完全透明（Alpha = 0）** | 市松模様・台座・背景紙・地面枠を描かない |

### 画風・アートディレクション
- **タッチ**: 西洋古典ファンタジー・ダークファンタジー調の手描き彩色（水彩・アクリル・鉛筆の混淆風）。
- **色彩**: 彩度を抑えた落ち着いたアースカラー（灰緑、湿った石色、深い土色、古びた鉄、鈍い金、淡い燐光）。
- **光源**: 左上からの柔らかな環境光。過度なハイライトや現代的ネオン発光を避け、松明や月光に照らされた風合い。
- **視点**:
  - **床・罠・床面ギミック**: 見下ろし（トップダウン／斜めトップダウン 約60度俯瞰）。隣接する床と自然に敷き詰め可能な構図。
  - **壁・門・階段・宝箱・結晶・オブジェクト**: 2.5D クォータービュー（正面やや上、見下ろし角30〜45度）。立体感と高さが視認できる構図。
- **禁止事項**: 文字・数字・記号・外枠・仕切り線・接地用の後付け枠線を描かない。

### 床・壁タイルの視認性契約（2026-10-22 改訂）

受領済みシート03/04では、床と壁がともに中央寄せの単体オブジェクト風（透明余白・丸い縁取り）かつ近い色相・明度で描かれ、44pxへ縮小すると通路と壁の判別がほぼ付かなかった（風切りの石道で下り階段への道が見つけられない事例）。再生成時は以下を必須とする。

| 項目 | 床タイル（各バイオーム枠01〜05・21〜22） | 壁タイル（枠06〜14） |
| --- | --- | --- |
| 余白 | **なし**。四辺いっぱいまで不透明、シームレスに連続 | **なし**。四辺いっぱいまで不透明、隣の壁と一続きの壁塊 |
| 視点 | 真上トップダウン | 真上トップダウン（上面＝天端を全面に描く。単独の柱・岩・樹木にしない） |
| 明度 | 明るい（目安60〜75%） | 暗い（目安15〜30%） |
| 色相 | 暖色（砂色・黄土・明るい土・淡灰の石畳） | 寒色（黒灰・深い青緑・濃い苔黒・暗褐） |
| 模様 | 細かく控えめ、低コントラスト | 粗く大きい、高コントラスト。目地・割れ目が隣タイルへ続く |
| 受入検査 | グレースケール化した迷路配置で通路が一目で追える／床・壁の明度差40%以上／3×3反復で継ぎ目なし／44px縮小でも判別可 | 同左 |

透明余白規則（四辺19px）は門・階段・宝箱・罠・装飾などの単体オブジェクトにのみ適用する。

> [!NOTE]
> 再生成までの暫定措置として、`exploration-ui.js` の描画時に画像壁を暗く減光（`rgba(3,7,9,0.58)`）し、床へ淡い暖色を重ね、通路に面する壁辺へ明るい縁線（`#e9d79f`）を描いて判別性を補っている。

## 2. 制作シート構成一覧

アセットは以下の4シート（計120セル）に分類して制作する。詳細なプロンプトと表は [MAP_ART_TABLES.md](MAP_ART_TABLES.md) を参照。

```
docs/
├── MAP_ART_SPEC.md                # 本仕様書（制作・レンダラ組込み契約）
├── MAP_ART_TABLES.md              # 全4シート・120項目の制作指示・フレーバー一覧
└── map-art/
    └── マップアセット共通プロンプト.md  # 画像生成AIへ渡す持ち運び用プロンプト
```

### シート概要

1. **Sheet 01: 探索構造物・ランドマーク・戦利品（30種）**
   - 出口／入口の石造りアーチ門、下層への階段、地域の主の祭壇／封印門
   - 宝箱（木製・鉄製・魔導・開封済み）、採集結晶（鉱石・薬草・原木・宝石）
   - 冒険者の遺留品／死体、探索パーティの現在地シンボル・方位マーカー

2. **Sheet 02: 地形ギミック・トラップ・障害物（30種）**
   - 水辺・浅瀬（通常・波紋・深水）
   - 崖・裂け目・高所段差（亀裂・岩棚・崩落）
   - 隠し通路・隠し扉（閉扉・開口・石壁擬態）
   - 仕掛け罠（トラバサミ・槍床・落とし穴・作動済み・解除済み）
   - 瘴気溜まり（有毒ガス・泥沼）、魔力異常床（魔方陣・放電ルーン）

3. **Sheet 03: 灰灯の林縁・森林・自然バイオーム（30種）**
   - 森林床（踏み固められた土、下草、落ち葉、露出した木の根）
   - 森林壁（鬱蒼とした大木、巨岩、密集した茨、倒木）
   - 装飾（光るキノコ、古代の道標、石碑、木漏れ日、獣道）

4. **Sheet 04: 地下迷宮・古代遺跡・鉱廊バイオーム（30種）**
   - 遺跡・鉱廊床（石畳、ひび割れた敷石、排水溝、砂利、鉱山レール）
   - 遺跡・鉱廊壁（切石積み壁、天然岩壁、崩れたレンガ、支保工の木枠）
   - 装飾（壁掛け松明、錆びた鎖、格子窓、転がる鉱石、彫刻柱）

## 3. ゲームエンジンへの組込み仕様

### 描画パイプライン（`exploration-ui.js` の `draw()` 改修契約）

1. **アセット定義のSSOT (`map-art.js`)**:
   モンスター画像（`BRPGMonsterArt`）と同様に、`BRPGMapArt` モジュールを新設：
   ```javascript
   const BRPGMapArt = {
     sheets: {
       structures: { src: 'map_sheet01_structures.png', width: 1145, height: 1374 },
       hazards:    { src: 'map_sheet02_hazards.png',    width: 1145, height: 1374 },
       forest:     { src: 'map_sheet03_forest.png',     width: 1145, height: 1374 },
       dungeon:    { src: 'map_sheet04_dungeon.png',    width: 1145, height: 1374 }
     },
     tiles: {
       // 各タイルID・種別と実切り出し矩形の対応
       'floor_forest': { sheet: 'forest', rect: { x: 0, y: 0, w: 229, h: 229 } },
       'wall_forest':  { sheet: 'forest', rect: { x: 229, y: 0, w: 229, h: 229 } },
       'exit_arch':    { sheet: 'structures', rect: { x: 0, y: 0, w: 229, h: 229 } },
       'stairs_down':  { sheet: 'structures', rect: { x: 229, y: 0, w: 229, h: 229 } },
       'chest_wood':   { sheet: 'structures', rect: { x: 458, y: 0, w: 229, h: 229 } },
       'crystal_node': { sheet: 'structures', rect: { x: 687, y: 0, w: 229, h: 229 } },
       'boss_seal':    { sheet: 'structures', rect: { x: 916, y: 0, w: 229, h: 229 } },
       // ...
     }
   };
   ```

2. **Canvas 2D 描画への適用**:
   `ctx.drawImage(img, sx, sy, sw, sh, dx, dy, dw, dh)` を使用。
   - `dw`, `dh` は現在のグリッドサイズ `z = 44px` に正確にスケール。
   - アセット画像が読み込み前、または未検品・未存在の場合は、**既存の幾何学プリミティブ描画（`rect`, `poly`, `arch`）へフォールバック**する二重安全構造とする。
   - 配布用ビルド（`scripts/build-pages.cjs`）の allowlist に受領したアセット画像を追加する。

## 4. 検品基準（受入条件）

1. **実寸と透過**:
   - PNG形式、1145×1374px（または同等比率）、完全透明背景。
   - 各セルの四辺に19px以上の透明余白があり、隣接セルにはみ出していないこと。
2. **視認性とスケール**:
   - 44×44px（Canvasタイルサイズ）に縮小しても、壁・床・宝箱・階段・トラップの形状が判別可能であること。
   - 暗い背景（`#0c171b`）およびダンジョン視野光（`#e1c48044`）に重ねても輪郭が破綻しないこと。
3. **世界観の整合**:
   - アッシェン・アトラスの灰灯の世界（黄昏、鉱物、深い森、古代遺跡）に合致し、ポップすぎるアニメ調やサイバー調を排除していること。
