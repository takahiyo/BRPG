# 受領マップアセットシートの整理記録

受領した4枚のマップアセットシートを整理。元ファイル名の末尾番号および各セルの絵柄・色調と制作表の並びを照合した。以下のID範囲は制作リストとの対応であり、全セルの名称・配置・透明余白を承認した意味ではない。ゲームへの組込みは検品を経て順次行う。

## 配置と命名

- 配置先：プロジェクト直下。モンスター画像や既存画像、`scripts/build-pages.cjs` のルート画像構成に合わせる。
- 命名規則：[MAP_ART_SPEC.md](../MAP_ART_SPEC.md) の描画契約定義と一致する `map_sheet01_structures.png` 〜 `map_sheet04_dungeon.png`。
- 全4枚で移動前後のSHA-256が完全に一致。再圧縮・リサイズ・切出し・透過加工は一切行っていない。

## 組込み前の注意

- 全シートが規格通りの 1145×1374 px（5列×6行、1枠 229×229 px）で生成されている。
- 実寸が一致するだけではゲーム描画への無条件適用とはせず、個別のセルごとに隣接枠へのはみ出し、境界切れ、透明余白、アイコン視認性を検品した上で、検品済みタイルから順次 `map-art.js` および `exploration-ui.js` の `draw()` へ接続する。
- 未検品・未登録のタイルについては、従来の Canvas 2D 幾何学描画へのフォールバックを維持する。
