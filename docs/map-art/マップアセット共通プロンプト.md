# マップアセット共通プロンプト

下のコードブロックを画像生成側の固定指示（システムプロンプトまたは共通指示）として設定し、その後に[[MAP_ART_TABLES]]（または制作対象シートの30枠リスト）を一つずつ渡す。

モンスターアートの制作規格（`docs/monsters/アセットシート共通プロンプト.md`）と完全互換の仕様（1145×1374px、5列×6行、1枠229×229px、透過PNG）を持ち、統一されたダークファンタジーの画風でダンジョンマップアセットを生成する。

```text
# BRPGマップアセットシート

ユーザーが渡すシート番号・テーマ・番号付きリストから、ダンジョン探索ゲーム用の独立したマップタイル／オブジェクト絵柄を1枚のシートに描く。プロンプトのみを求められた場合は指示文を出力し、画像生成はしない。モンスター・アイテム・マップで画風・照明・配置規則を共通にする。

## 配置と画像仕様

- 横5列×縦6行、計30枠。各枠は正方形。キャンバス比率は幅:高さ=5:6。
- 基準サイズは1145×1374px、1枠229×229px。
- 1145×1374pxを直接指定できない場合は、利用可能な同等以下のサイズで幅:高さ=5:6を優先し、返却された実寸を記録する。比率が違う場合は別工程で余白調整・再配置してから切り出す。
- 枠は配置上の仮想領域。枠線、仕切り線、グリッド線、外周装飾、番号、名前、文字、署名、ロゴ、透かしは一切描かない。
- 並びは左上から右へ、次に下の行へ進む行優先。1行目が枠1〜5、2行目6〜10、3行目11〜15、4行目16〜20、5行目21〜25、6行目26〜30。「1列目に1〜5」と縦方向へ解釈しない。
- 入力のT等のIDは管理用で、画像へ書かない。入力順を変えず、1枠に指定対象を1点描く。指定にない対象や、別枠の対象を追加しない。
- 30件未満なら残りは空の透明枠とし、前の対象を複製して埋めない。複数対象を一枠にまとめない。
- 全体にも各枠にも額縁や可変余白を付けず、均等な正方形領域へ配置する。対象自体の周囲には下記の安全余白を確保する。

## 背景・光・画風

- 第一希望は実際のアルファチャンネルを持つ透明PNG。透明を模した市松模様や背景グリッドは描かない。
- 透明出力が利用できない場合だけ、背景を全面単色の薄い中立灰色 #E8E8E8 とする。紙目、羊皮紙、グラデーション、不要な風景は描かない。緑の背景は植物素材と干渉するので使わない。
- 西洋ファンタジー図鑑・クラシックRPG風の、精緻な手描き彩色イラスト。水彩・アクリル・鉛筆の混淆風で、やや写実的な質感に、マップチップとして縮小表示（44×44px等）しても読める輪郭と整理した明暗を組み合わせる。写真的な背景や現代的3Dレンダー風・フラットデザインのピクトグラムにしない。
- 全対象で柔らかな左上光、落ち着いたアースカラー（灰緑、湿った石色、深い土色、古びた鉄、鈍い金、淡い燐光）を保つ。過度なネオン発光や派手な原色は避ける。
- 視点と構図：
  - 床・罠・床面ギミック・水たまり：見下ろし（トップダウン／斜め俯瞰 約60度）。隣接する床タイルと自然に接続・敷き詰め可能な構図とする。
  - 壁・門・階段・宝箱・結晶・障害物：2.5D クォータービュー（正面やや上、見下ろし角30〜45度）。タイルの立体感と高さがひと目で視認できる構図とする。
- 実寸比率：枠内で視認しやすい大きさへ調整する。鍵穴や小さなキノコでも、縮小時に潰れないよう特徴的なシルエットを強調する。

## 切れ・隣枠干渉の防止

- 各対象の本体、枝、突起、煙、発光の全域は、枠の中央およそ76%〜84%以内に収める。
- 四辺の最低8%（229px枠で約19px以上）は完全な透明余白とする。
- 隣の仮想枠へ一切はみ出させない。火、煙、粒子、光条、木の根の先まで同じ規則を適用する。
- 地面への落ち影は対象本体の直下に自然に描いてよいが、枠外へ大きく伸びる強い影は描かない。

## 対象種別ごとの扱い

1. 探索構造物（門・階段・祭壇）：
   - 通行可能か進入不可かが直感的に分かる開口部・階段の奥行きを表現する。
   - 封印門やボス祭壇は厳粛で不穏なオーラを持たせるが、枠外へ広がる長大なエフェクトは控える。

2. 宝箱・採取ノード・遺留品：
   - 宝箱は蓋の閉じた状態または半開き状態の素材感を明確にし、金具や装飾を描き分ける。
   - 魔導結晶や薬草は自生している塊として描き、採集対象としての存在感を際立たせる。

3. トラップ・環境ハザード：
   - 作動前の潜伏状態または作動時の明確な危険性を象徴する形状にする。
   - 毒ガスや魔力異常は床面を中心に凝縮させ、上部への拡散を枠内に抑える。

4. 壁・床タイル：
   - 壁は「通行不能な境界」として重厚に描く。
   - 床は「通行可能な地表」として平坦感を保ち、過剰に凹凸を強調して歩行キャラクターの視認性を邪魔しないようにする。

## 出力確認

画像を生成した場合は、実寸、5列6行・入力順・件数・欠落・重複・文字の混入・透明背景・切れ・隣枠へのはみ出しを確認する。1145×1374pxなら229pxごとの境界で切り出し、外周まで本体が欠けず透明余白が残ることを検品する。暗色・明色の両背景で色にじみや矩形の残りを確認する。
```
