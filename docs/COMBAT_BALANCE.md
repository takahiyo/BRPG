# 距離戦闘の固定シード計測

2026-10-22 / C1。再実行は `node test-combat-balance.cjs`。

## 条件と合否

- 3地域（forest_edge Lv1、rocky_path Lv2、crystal_cave Lv10）×5編成×30シードの450戦を2回実行し、全戦の勝敗・ターン・資源変化が一致することを検証（実行数900戦）。シードは `Math.imul(i + 1, 0x9e3779b1) >>> 0`（i=0..29）。小さい連番だけで乱数の初回値が偏ることを避ける。
- 同じ地域・シードでは全編成の敵ID・隊列・LIFE・攻撃・魔力が一致することを確認する。各戦の前に状態を初期化し、英雄のLvを地域Lvへ合わせ、LIFE/MANA/SPを満タンにする。
- 木製Q1・耐久60の武器のみ、防具なし。初期の薬を保持。既存の自動入力と軍師支援を使い、手引書/温存/撤退ルールは追加しない。成長Ptの配分や装備更新はしない。
- 全員に行動が入り、攻撃対象へ距離が届き、自動技が最後のMANAを使い切らず、保存が有効であることを検証。全戦100ターン以内に終了し、再現結果が一致することを必須とする。
- 入口の新規開始編成は30戦中24勝以上を最低限の回帰ガードとする。これは製品全体の難易度目標や統計的な勝率保証ではない。後衛の届く装備では旧近接編成より防御待機が少ないことも検証する。

## 判断と限界

新規開始時のみ後衛2人の木製武器を杖へ変更し、距離の届かない初期装備を解消した。固定シードの入口戦は旧装備20/30勝から29/30勝、防御待機は平均12回から0回へ減少。敵の能力・ダメージ係数・金貨・薬数は変更しない。既存セーブの装備は保持し、強制交換しない。

Lv10では旧近接編成の方が技を多く使い勝利数も多い。射程が長ければ常に強いという結果ではない。基本自動入力は主に前衛から狙うため、今回の槍と杖の結果は一致したが、後衛を優先する手動操作や弱点戦術での同等性を意味しない。

同Lv・初期武器・防具なしの独立した通常戦のみであり、連戦経済・移動消耗・装備更新・ボス・高Lv地域・全職・各種手引書・実際の最適操作の受入は未完了。特にLv2で新規4人の勝利が18/30に留まる点は、成長配分と工房/商店での装備更新を含む次段階で確認する。今回の結果だけで敵を弱体化しない。

## 同時に修正した境界

- 距離フォールバックや軍師支援を含む最終自動入力で、MANA/SP温存と最後のMANAを保護。手動では最後のMANAを使う選択を維持する。
- 全体技は開始時の射程と対象集合を維持し、途中で武器が壊れても未攻撃対象へ毒だけ付く状態を防ぐ。次の行動は壊れた武器の射程で判定する。
- 気絶した前衛は敵味方どちらに対しても前列の遮蔽を維持しない。到達判定に戦闘参加可能者を使う。
