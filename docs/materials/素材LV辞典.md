# 素材LV辞典

原典：[[素材：鉱石など]]。共通ルール：[[LV設計ルール]]。

原典の素材表257行を掲載順で収録し、既存アイテム分類に必要な基礎素材8行を補完した。原文見出しは別名を含めて保持し、表示名は表記用に整理する。併記された概念は一行のまま扱う。

適正LVはBRPG独自の暫定的な使用・出現範囲であり、原典のランクや各作品の公式序列をLVへ換算した値ではない。下限は導入の目安、上限300は高LVでも使用可能であることを示す。原典で同じ素材の別解釈に当たる行も、照合のため別IDで保持する。

素材カテゴリは機械照合用の分類。鉄鋼製の金属は `金属,鉄系`、鉱石・宝石・結晶は `石`、繊維素材は `布`、工業用セラミックは `陶磁` とする。実体を特定しにくい超常物質・魔法エネルギーは `魔力` にまとめる。
