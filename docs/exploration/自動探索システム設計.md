# 自動探索システム設計

2Dランダムマップを、手動操作と放置自動探索の両方で遊ぶ。序盤の移動方針は「右の壁沿いに歩く」だけ。探索で手引書を入手するか、案内人・罠師などを編成すると、行動の選択肢が増える。選択肢が増えることと、敵や罠を見抜けることは別の成長とする。

関連：[[探索行動と手引書辞典]]、[[職業とスキルの運用規則]]、[[職業辞典_冒険と戦闘]]、[[職業辞典_生活と奇想]]、[[スキル辞典_冒険と戦闘]]、[[スキル辞典_生活と奇想]]、[[探索レベルデザイン]]、[[クラフトシステム設計]]。

本書は暫定仕様。ランダムマップ生成・経路探索・オフライン計算のゲーム実装は今回の対象外。条件、優先順、停止理由、検証例を先に定義する。

## 1. 自動探索が見てよい情報

マップは床・壁・扉・階段などのセルから成る。地形乱数とイベント乱数は分離して保存し、手動と自動で同じワールドを進める。プレイヤー未発見の地形・敵・罠・宝箱を自動AIだけが参照してはならない。

各セルは「未観測」「既知地形」「現在視認」の状態を持つ。敵位置には最終観測時刻、罠には発見済み／推定／解除済みを保存する。古い敵位置は安全の保証にならず、再観測で更新する。離れた地点の罠や敵を読み取る能力がある場合も、範囲・費用・遮蔽条件をスキル側に持たせる。

敵回避は見えた敵または足跡・音から推定できた危険を迂回する判断。罠回避は発見済み・推定済みの罠セルへ踏み込まない判断。未知の罠を完全回避する能力ではない。罠捜索は時間を使って情報を増やす別行動、罠解除は道具と技能を必要とするさらに別の行動である。

## 2. 初期行動と行き詰まり

B01「右壁追従」は、進行方向に対して右→直進→左→後退の順に、既知または目視できる通行可能な隣接セルを選ぶ。壁が途切れた広場でも同じ順序を使う。施錠扉、段差、障害物は勝手に突破できない。

壁沿い移動は、ループや独立した壁があるダンジョンでは全探索・出口到達を保証しない。同じ位置・向き・扉状態の組を3回訪れ、未探索セルの発見がなければループを検知する。B07が未設定・使用不能なら「同じ場所を巡回」で安全停止する。B07が設定済みで使用可能なら、停止より先に未選択枝へ向かう候補を一度評価し、候補がない場合に停止する。同じ枝への再試行を繰り返さないよう、試行済み経路も記録する。

行動解放前でも、プレイヤーは手動で進路を変えたり、帰路を自分で指定して撤退したりできる。停止している間はオフライン探索時間を消費しない。手引書を持っていないことを理由に、無限に歩いて全滅する仕様にはしない。未解放でも設定できるHP・物資の保護閾値は「停止」だけを行い、自動の帰路選択や回復は行わない。

## 3. 行動の解放条件

行動Bごとに、次のどちらかを満たすと設定候補に表示する。

```text
恒久解放 = 対応手引書を研究済み AND パーティー平均LV >= 行動の手引条件LV
専門職解放 = その行動を許可するスキルを習得済みの有効な専門職が同行
使用可能 = (恒久解放 OR 専門職解放) AND その場の実行条件
```

専門職経由は手引書と平均LV条件を代替するが、スキル本人の習得LV・道具・知覚・地形条件を無視しない。したがって序盤の案内人はB09の回避判断を先行提供できるが、見えない敵や唯一の通路を塞ぐ敵を消せるわけではない。

手引書を拾った時点では所持品。拠点または安全な休息で研究すると遠征隊の共有知識へ登録され、以後は本の携帯不要。専門職の在籍だけでは恒久解放されない。育成を恒久知識へ移す場合は別途「教本執筆」等の研究と検証を必要とし、今回の初版では自動変換しない。

### 平均LVの定義

出発時に選んだ実参加メンバーのキャラクターLVの算術平均を切り捨てる。控え・拠点NPC・荷物扱いの召喚物は除外する。戦闘不能者は帰還まで人数に含め、戦闘不能にした途端に平均LVが上がる挙動を防ぐ。メンバーの正式な加入・離脱時は再計算する。

必要な専門職は生存・行動可能・同じ隊内であることが必要。戦闘不能・分断・沈黙などスキル固有の条件が崩れたら、次の判断前に再評価する。失われた高度行動を黙って右壁追従へ切り替えず、依存する行動を停止して理由を表示する。事前に許可した代替行動がある場合のみ切り替える。

## 4. 方針の優先順と競合解決

すべての解放済み行動を同時に発動するのではなく、出発前に最大6個の行動を優先順付きで設定する。B01は移動方針の既定値として別枠。戦闘の通常コマンドと常時受動効果も別枠で扱う。

| 優先層 | 内容 | 同時成立時 |
|---|---|---|
| 0 | 通行不能、必須専門職喪失、解消候補のないループ、安全停止条件 | 移動を止める。B07のループ解消候補は停止確定前に評価 |
| 1 | 使用可能かつ設定済みのB20・B22等による撤退条件、戦闘からの離脱判断 | 帰路行動も使用可能なら撤退路へ。なければ停止または指定戦闘方針 |
| 2 | 罠回避・危険地形・敵回避 | 危険セルを候補から外す |
| 3 | 休息・灯火・物資・隊列維持 | 安全に実行できる場合のみ補給 |
| 4 | 採集・宝箱・交渉など目的行動 | 設定された優先順位で選択 |
| 5 | 未探索・階段・壁追従など移動 | 残った通行候補から次のセルを選ぶ |

危険を避けた結果、通行候補が空なら危険回避を勝手に解除しない。「待機」「既知の安全側へ戻る」「停止」の事前指定から選ぶ。敵回避と宝箱優先が競合すれば敵回避を優先する。帰還中は新しい宝箱のために寄り道しない。

敵の脅威度LVは観察・鑑定で得た推定値を使う。推定不能な敵は「未知」と表示する。B10を使用可能かつ設定済みの場合は、未知敵への接近を避ける判断を既定とする。B09はLV推定に関係なく発見済み敵を回避する。B09/B10等を使用していない初期隊に、これらの迂回判断を無料で与えない。平均LVより低い敵でも相性や消耗次第で危険なので、LV比較は無敵判定にしない。

B20・B22は物資・負傷から「帰還する」と決める行動で、経路の選び方とは別。自動的に拠点側へ移動するには、B03・B06・B39のいずれかも設定済み・使用可能であることを要求する。帰還判断と帰路選択はそれぞれ1枠を使う。帰路行動がない場合や通行可能な帰路が見つからない場合は停止する。無料の保護閾値による停止は、対応するB20/B22を設定した場合のみ自動帰還判断へ置き換える。

## 5. 1回の判断処理

```text
観測更新 → パーティーと行動解放を再判定 → B07のループ解消候補を評価 → 停止条件確認
→ 設定行動が候補を作る → 危険・物理条件で絞る → 優先順位で1行動を選ぶ
→ 移動／捜索／待機などの時間を消費 → 遭遇を解決 → 履歴を保存
```

移動と捜索を同じ無料処理にしない。暫定の時間単位は通常移動1、慎重捜索2、解除3、休息10、短期待機1とし、移動以外の間にも巡回敵や環境は進行する。具体的な実時間秒数、戦闘時間、罠判定確率は後で設定する。

罠捜索が失敗した地点へ何度でも無料で再試行できないようにする。同じ条件での反復捜索は結果を固定し、道具・技能・照明・別方向の観測など条件が変わった時だけ再判定する。未発見でも「罠なし確定」と表示しない。

## 6. 放置・オフラインの扱い

オフラインは同じ判断処理を順に実行する。単に経過時間×報酬率で宝を増やすと、回避・罠・行き詰まりが無意味になるため採用しない。計算負荷を抑える場合はイベントのない区間をまとめるが、危険・観測・資源消費の境界で分割する。

暫定上限は1遠征あたり実時間8時間相当、判断10万回までの早い方。いずれかに達したら進行を停止し、残り時間で自動再出発はしない。通信再送・アプリ再起動でも同じ遠征IDと処理済みイベント番号を使い、報酬の二重取得を防ぐ。

停止は脱出や回復ではない。停止地点・負傷・所持品を維持し、再開時にそこから進む。帰還経路を知らない初期隊には「安全な帰還」を捏造しない。全滅時の損失や救助は別ルールとし、放置だけ特別に無敵にはしない。

出発画面で、目的、行動6枠、回避対象、保護停止のHP・食料条件、解放済み行動による自動帰還条件、専門職への依存、最大遠征時間を表示する。停止と自動帰還を同じ設定名にしない。未解放項目には「手引書未研究」「平均LV不足」「必要職が不在」を分けて出す。

## 7. 最低限の受入ケース

| 状況 | 期待する動作 |
|---|---|
| 初期隊が分岐へ来る | B01で右側から探索。未解放の最短路を使わない |
| 輪状通路を巡回 | 3回の反復を検知。B07が設定済み・使用可能なら別候補を選び、使えない場合や候補なしの場合は停止 |
| 敵回避はあるが隠れた敵がいる | 観測できるまで回避対象にならない |
| 罠回避はあるが罠捜索はない | 発見済み罠だけ迂回。未知罠の保証なし |
| 敵と罠が唯一の出口を塞ぐ | 設定を破って突入せず、指定の待機・停止・戦闘判断 |
| 案内人が戦闘不能 | 専門職だけに依存する行動を停止。手引条件達成済みなら継続 |
| 複数人の平均が9.9、条件LV10 | 切捨て9なので手引経由では未解放 |
| 荷物が満杯で宝箱がある | 廃棄・持帰りの事前方針に従う。自動で希少品を捨てない |
| オフライン計算を再送する | 同じイベント番号の報酬は追加しない |
| 高LV隊に低LVの罠師がいる | 行動解放はできても、高難度罠の発見・解除判定は別途必要 |

手引書の落下率と職業ごとの具体的判定補正は未確定。まず、手引書・専門職・平均LV・道具がそれぞれ別の役割を持つ構造を検証する。
