# 探索行動と手引書辞典

40の行動と39冊の手引書を仮配置する。B01のみ初期解放。手引書の入手・研究と、使用時のパーティー平均LV条件を分ける。専門職のスキルが提供する行動は、手引書・平均LV条件を代替できるが、発見判定や道具は代替しない。詳細は[[自動探索システム設計]]。

手引書の出現下限〜上限は報酬抽選用で、強制的な入手順ではない。上限300として終盤の再入手・交易を認める。ここにない戦闘性能や成功確率は後で調整する。「罠を避ける」は危険を認識した後の判断を増やすものである。

B20・B22の帰還判断で実際に自動移動するには、帰路を選ぶB03・B06・B39のいずれかも使用可能・設定済みであることが必要。判断と帰路で各1枠を使う。未解放時でも設定できる保護閾値は停止のみを行う。B07はループ検知時に別枝を評価し、候補がない場合に停止する。

## 入手経路と重複本

低級本は街道商、初心者向け依頼、低LV帯の宝箱にも置く。難所を突破するための本が、その難所の奥からしか出ない配置は避ける。重要なB03・B09・B15・B19・B20・B22は、ドロップのほか購入または依頼報酬でも入手できる。

高級本は対応する探索・研究依頼、遺構の記録、専門家からの指導でも得られる。重複本は売買・他隊への譲渡・研究資料に使い、同じ行動を重ねて万能化しない。書き込み入り、著名案内人の署名付き、初版本などの称号で交易価値を変えられるが、基本内容が同じなら行動解放は同じにする。

手引書の物理素材は紙や革などの部品で構成できるが、紙を作れるだけでは内容の知識は生まれない。[[クラフトシステム設計]]の製法・作者・来歴と同様に、執筆者が検証した内容を別のデータとして保存する。
