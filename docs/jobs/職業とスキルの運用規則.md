# 職業とスキルの運用規則

300職と180スキルの初期案を、戦闘力の上下だけでなく探索・製作・交易・生活の役割へ分ける。職業名は世界の肩書きであり、同じLVでも何に役立つかが異なる。関連：[[職業辞典_冒険と戦闘]]、[[職業辞典_生活と奇想]]、[[スキル辞典_冒険と戦闘]]、[[スキル辞典_生活と奇想]]、[[自動探索システム設計]]。

## 職業とキャラクターの関係

初版では主職1つを選び、主職に紐付く3スキルを候補として持つ。職業LVをさらに追加せず、就業条件とスキル習得条件はキャラクターLV1〜300で評価する。加工LV・魔法加工LV・エンチャントLVは、[[クラフトシステム設計]]どおり独立した技能である。

職業の就業LV下限以上になり、拠点で訓練・資格確認を終えると転職できる。具体的な資格・費用は後で個別レシピにする。上限300は全職が最終帯まで在籍できることを意味し、上級職への強制転職はない。職業名の「王」「神」「伝説」等は世界観上の職能名候補で、政治的地位をLVだけで授与するものではない。

スキルは主職の候補にあり、本人がそのスキルの習得LV下限以上なら、拠点で習得できる。候補3つが即座にすべて使えるわけではない。派生職の就業LVより低い習得LVのスキルは、就業時点で習得可能になる。スキル1〜3は一覧順で、厳密な初級・中級・奥義の順とは限らない。

習得履歴は保存するが、転職後に元職の全スキルを同時使用しない。初版は現在の主職に紐付くスキルだけ有効とし、副職・継承枠は保留する。全職巡回による探索能力の無制限積み上げを防ぎ、編成の意味を残す。

## スキルの5種別

| 種別 | 使用場面 | 初版の制約 |
|---|---|---|
| 受動 | 感知・耐性・管理補助 | 観測範囲・条件・対象がある。同名効果は加算しない |
| 戦闘 | 攻防・支援・離脱 | 戦闘の資源・時間を消費。具体値は保留 |
| 探索 | 移動・捜索・地形操作 | 行動解放と実行判定を分離する |
| 制作 | 製作・研究・修理 | 加工LV、技術、設備、素材条件を免除しない |
| 交易 | 鑑定・交渉・流通 | 所有権、相手の意思、来歴の真偽を自動成立させない |

「解放行動」欄にBxxがあるスキルは、[[探索行動と手引書辞典]]のその行動を専門職経由で提供する。複数IDは各行動を候補へ追加する意味で、1枠で同時に全部実行する意味ではない。欄が「-」の技能は、自動探索の方針を新たに解放しない。

習得済みでも、提供者の戦闘不能・分断や技能固有の制約で使えない場合がある。感知技能と判断技能は別で、罠師がいれば全罠を必ず見つけられるわけではない。同種の感知スキルを複数積んだ場合は最も条件のよい一つを使い、全員分の成功率を足して100%にしない。

## 序盤の専門職の価値

案内人は低LVでも視認敵回避の判断を提供する。罠師は既知罠回避と罠捜索を提供する。これにより、平均LV条件や手引書が揃う前から探索の事故を減らせる。一方、前衛一人を専門職に置き換えると戦闘の継続力や瞬間火力を失う。探索で戦闘を避けやすくなること自体が、その代償への見返りとなる。

手引書が揃った後も、専門職には感知精度、探索時間、消耗、調査対象などで役割を残す。ただし数値補正は後で比較テストし、同じ行動が解放済みというだけで専門職を無価値にも必須にも固定しない。

## 王道・生活・ネタ職の扱い

戦士や魔術師は直接的な戦闘役、商人や機械工は遠征の前後も含む支援役、清掃職や芸人は限定された場面で独特な解決策を持つ。ネタ職も単なる弱体化枠にはせず、「どこなら役立つか」「どこでは困るか」を各行に書く。

職名の違いだけで別の300成長曲線を実装しない。初版は30系統の共通スキルを組み合わせ、派生職は役割・解放LV・3スキルの組合せ・固有フレーバーで分ける。職業固有の新しい効果を増やす場合は、既存スキルの表現だけで誤認させず、スキルIDまたは明示したパラメータを追加する。

職業のフレーバーは効果の保証ではない。たとえば「迷宮に愛される」という説明があっても、地形を透視したり報酬を無限に増やしたりはしない。

## 編成テスト案

| 編成 | 期待する強み | 比較する弱点 |
|---|---|---|
| 戦闘職4人 | 正面戦闘を短く終える | 未知罠・ループ・消耗への対応 |
| 戦闘職2人＋案内人＋罠師 | 低LVから危険回避・捜索が可能 | 強制戦闘での手数不足 |
| 戦闘職2人＋治療師＋商人 | 継戦と回収品の価値 | 地形処理と初見情報 |
| 案内人＋罠師＋運搬職＋学者 | 調査・採集・交易寄り | ボスや逃げ場のない戦闘 |
| 戦闘職＋機械工＋付与師＋運搬職 | 現地部品調達と工房への持帰り | 現地設備不足、長い製作時間 |

4人は比較用の仮定で、実際のパーティー人数をここでは固定しない。職業ごとの装備制限・HP係数・命中補正・スキル消費量は未設定。先に行動・役割・習得LVの整合性を確認する。
