# スキル辞典_冒険と戦闘

関連：[[職業とスキルの運用規則]]・[[職業辞典_冒険と戦闘]]・[[探索行動と手引書辞典]]・[[自動探索システム設計]]

15系統各6技能、計90件。習得LVは本人のキャラクターLVで判定し、現在の主職の候補であることと拠点での習得が必要。全スキルの上限は300、具体的な消費量・成功率・能力補正値は保留する。

解放行動はBxxの設定候補を専門職経由で追加する。複数IDは同時実行を意味せず、本人が生存・同行・行動可能で、道具・地形などの実行条件を満たす必要がある。基本B01は全員既定。未観測地形・隠れた敵・未知罠を自動取得せず、見えた情報と推定の範囲で判断する。捜索は時間を消費し、失敗しても安全確定にならず、同条件の反復で無料再抽選しない。受動効果にも範囲と条件があり、同種効果を人数分加算しない。
