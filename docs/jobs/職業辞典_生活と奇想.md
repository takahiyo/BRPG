# 職業辞典：生活と奇想

[[スキル辞典_生活と奇想]] ／ [[職業とスキルの運用規則]] ／ [[自動探索システム設計]] ／ [[クラフトシステム設計]]

15系統・各10職の150職。各系統の6スキルから異なる3つ組を割り当てる。就業は本人LV下限と拠点の訓練・資格確認による。上限300は在籍継続可能な上限で、低級職の役割も残す。各スキルは本人が習得LVへ達してから拠点で順に習得でき、就業だけで3技すべてが使用可能になるわけではない。就業時点で条件を満たす技はそこで習得可能。

役割は割当スキルの使い道、フレーバーは雰囲気の創作であり固有の追加効果ではない。制作職でも加工・魔法加工・エンチャントの独立技能LVと技術・設備・レシピを要する。探索の専門職解放は手引書・平均LVを代替するが、未観測情報・道具・時間・安全を与えない。
