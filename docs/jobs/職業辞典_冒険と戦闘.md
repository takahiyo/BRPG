# 職業辞典_冒険と戦闘

関連：[[職業とスキルの運用規則]]・[[スキル辞典_冒険と戦闘]]・[[自動探索システム設計]]

冒険・戦闘側の15系統150職。就業LVと習得LVは本人のキャラクターLVで判定し、全職の在籍上限は300。3スキルは現在の主職が提供する習得候補で、就業時に即すべて付与されない。各スキルの習得LVを満たして拠点で習得したものだけ使用でき、転職後は現在の主職の候補のみ有効。能力補正の具体値は保留する。

役割文は3候補を順に習得した時の運用方向で、候補外の能力や成功を保証しない。探索行動の解放は観測・発見・解除の成功とは別。B01右壁追従は全員の既定行動であり、専門職が追加する行動も現地条件と設定枠に従う。
